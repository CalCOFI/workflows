  • Show All Code
  • Hide All Code

Published

2026-10-21

Overview

The Scripps Pelagic Invertebrate Collection (PIC) holds the invertebrate portion of the CalCOFI net samples; SWFSC sorts the same nets for fish eggs and larvae. This notebook gives each PIC Parent Net Event (PNE) the SWFSC NetId of the net (cod end) it came from, so PIC records can link to the ichthyoplankton counts and the other net-level data.

It is part 2 of the matching begun in February (first pass), which matched by tow. As Ed Weber pointed out, a bongo tow fills two nets, often starboard to formaldehyde and port to ethanol, so a tow-level match cannot say which NetId a PIC record belongs to. Here the match is per net:

  • Inputs. Linsey Sala’s PNE table of 2026-10-19 (CalCOFI expeditions only) and the SWFSC nets as released in the CalCOFI integrated database, so cruises, ships, NODC codes and stations are in the database’s cleaned vocabulary, not the raw SWFSC export.
  • Scope. CalCOFI proper, 1951 onward (Ed Weber: the 1949–50 nets are not part of the standard SWFSC data). Net types SWFSC does not sort for ichthyoplankton (PRPOOS, HSN, ring nets, …) stay in the crosswalk, marked not_sorted, so they still join the wider interoperability work.
  • Rules (libs/pic_net_match.R, asserted by tests/testthat/test-pic_net_match.R):
    1. the PIC net type maps to an SWFSC tow type, which must agree;
    2. a candidate tow is at the same station (line + station) within 36 h, or within 5 km and 12 h;
    3. the station match ranks first, then the nearest time, then distance;
    4. the preservative picks the net: formaldehyde is the starboard net, ethanol the port net; a tow with a single net gives that net;
    5. each SWFSC net goes to one PIC record and each record to one net: pairs are taken in rank order while both are free, so a record whose nearest net went to a closer record falls back to its next candidate; one left with none is a conflict;
    6. a PNE record identical to an earlier one (expedition, station, date, time, net type, preservative) is a duplicate, pointing to that record in duplicate_of, and is not matched.
  • Checks. The time difference of station matches must sit at zero (it would show a time-zone slip). The 139 PNE records that already carry SWFSC’s NetId must be reproduced wherever their nets are in the release.

4 Match

Code 
# identical PNE records describe one net event: match the first only
pne$duplicate_of <- pic_duplicate_of(
  pne, c("expedition_code", "site_key", "date", "start_hhmm", "net_type", "preservative"))

m <- pic_match_nets(
  pic  = pne |> filter(year >= 1951, is.na(duplicate_of)) |>
    select(pic_id, site_key, datetime_utc, latitude, longitude, tow_type, net_side),
  nets = nets |> filter(!is.na(datetime_utc)) |>
    select(net_key, tow_key, site_key, datetime_utc, latitude, longitude, tow_type, net_side))

xwalk <- pne |>
  left_join(m, by = "pic_id") |>
  mutate(status = case_when(
    year < 1951           ~ "pre_1951",
    !is.na(duplicate_of)  ~ "duplicate",
    TRUE                  ~ status)) |>
  left_join(
    nets |> select(net_key, net_uuid, cruise_key, swfsc_site_key = site_key,
                   swfsc_tow_type = tow_type, swfsc_net_side = net_side,
                   swfsc_datetime_utc = datetime_utc, ship_name_swfsc = ship_name,
                   ship_nodc),
    by = "net_key")

stopifnot(
  "one row per PIC record" = nrow(xwalk) == nrow(pne),
  "each SWFSC net is used once" = !anyDuplicated(na.omit(xwalk$net_uuid)))

xwalk |>
  count(status, name = "records") |>
  mutate(pct = round(100 * records / sum(records), 1)) |>
  datatable(caption = "Match status, all PIC records")

4.1 Of the nets SWFSC sorts

The rate that matters is over records whose net SWFSC sorts for ichthyoplankton, from 1951.

Code 
xwalk |>
  filter(!status %in% c("pre_1951", "not_sorted", "duplicate")) |>
  count(net_type, status, name = "records") |>
  pivot_wider(names_from = status, values_from = records, values_fill = 0) |>
  mutate(total = rowSums(across(where(is.numeric))),
         pct_matched = round(100 * matched / total, 1)) |>
  arrange(desc(total)) |>
  datatable(caption = "Match status by PIC net type (sorted nets, 1951+)")

4.3 Time check

PIC times are local Pacific Standard Time and the release keeps UTC. If the conversion is right, a station match’s released tow time minus its PIC start time is near zero; an hour or eight-hour offset would show a time-zone slip.

Code 
tc <- xwalk |>
  filter(status == "matched", match_method == "station", time_known) |>
  mutate(
    decade = 10 * (year %/% 10),
    dt_signed_hr = as.numeric(difftime(swfsc_datetime_utc, datetime_utc, units = "hours")))

tc |>
  group_by(decade) |>
  summarize(
    records          = n(),
    median_hr        = median(dt_signed_hr),
    pct_within_1h    = round(100 * mean(abs(dt_signed_hr) <= 1), 1),
    pct_off_by_7_9h  = round(100 * mean(abs(dt_signed_hr) >= 7 & abs(dt_signed_hr) <= 9), 1)) |>
  datatable(caption = "Released tow time − PIC start time (PST → UTC), station matches")

6 What did not match

no_candidate: no SWFSC tow of that type at that station within 36 h, nor within 5 km and 12 h. no_net: the tow was found but its net could not be picked (a two-net bongo with no preservative, or no net on that side). conflict: every net the record could take went to a closer PIC record. duplicate: the record repeats an earlier one (duplicate_of) field for field, so only the earlier one is matched.

Code 
cruise_ym <- nets |>
  distinct(cruise_key) |>
  mutate(ym = substr(cruise_key, 1, 7))

xwalk |>
  filter(status %in% c("no_candidate", "no_net", "conflict")) |>
  mutate(ym = format(date, "%Y-%m"),
         swfsc_has_month = ym %in% cruise_ym$ym) |>
  count(expedition_code, ym, swfsc_has_month, status, name = "records") |>
  arrange(desc(records)) |>
  datatable(caption = "Unmatched sorted records by expedition (swfsc_has_month: the release has an SWFSC cruise that month)")

um <- xwalk |>

```{r}
  mutate(datetime_utc = force_tz(datetime_utc, "UTC"))

cat(glue(

  "{format(n_distinct(nets$tow_key), big.mark = ',')} tows, ",
```

## Match

```{r}
#| label: match

# identical PNE records describe one net event: match the first only
pne$duplicate_of <- pic_duplicate_of(
  pne, c("expedition_code", "site_key", "date", "start_hhmm", "net_type", "preservative"))

m <- pic_match_nets(
  pic  = pne |> filter(year >= 1951, is.na(duplicate_of)) |>
    select(pic_id, site_key, datetime_utc, latitude, longitude, tow_type, net_side),
  nets = nets |> filter(!is.na(datetime_utc)) |>
    select(net_key, tow_key, site_key, datetime_utc, latitude, longitude, tow_type, net_side))

xwalk <- pne |>
  left_join(m, by = "pic_id") |>
  mutate(status = case_when(
    year < 1951           ~ "pre_1951",
    !is.na(duplicate_of)  ~ "duplicate",
    TRUE                  ~ status)) |>
  left_join(
    nets |> select(net_key, net_uuid, cruise_key, swfsc_site_key = site_key,
                   swfsc_tow_type = tow_type, swfsc_net_side = net_side,
                   swfsc_datetime_utc = datetime_utc, ship_name_swfsc = ship_name,
                   ship_nodc),
    by = "net_key")

stopifnot(
  "one row per PIC record" = nrow(xwalk) == nrow(pne),
  "each SWFSC net is used once" = !anyDuplicated(na.omit(xwalk$net_uuid)))

xwalk |>
  count(status, name = "records") |>
  mutate(pct = round(100 * records / sum(records), 1)) |>
  datatable(caption = "Match status, all PIC records")
```

### Time check

PIC times are local Pacific Standard Time and the release keeps UTC. If the
conversion is right, a station match's released tow time minus its PIC start
time is near zero; an hour or eight-hour offset would show a time-zone slip.

```{r}
#| label: time-check

tc <- xwalk |>
  filter(status == "matched", match_method == "station", time_known) |>
  mutate(
    decade = 10 * (year %/% 10),
    dt_signed_hr = as.numeric(difftime(swfsc_datetime_utc, datetime_utc, units = "hours")))

tc |>
  group_by(decade) |>
  summarize(
    records          = n(),
    median_hr        = median(dt_signed_hr),
    pct_within_1h    = round(100 * mean(abs(dt_signed_hr) <= 1), 1),
    pct_off_by_7_9h  = round(100 * mean(abs(dt_signed_hr) >= 7 & abs(dt_signed_hr) <= 9), 1)) |>
  datatable(caption = "Released tow time − PIC start time (PST → UTC), station matches")
```

## What did not match

`no_candidate`: no SWFSC tow of that type at that station within 36 h, nor
within 5 km and 12 h. `no_net`: the tow was found but its net could not be
picked (a two-net bongo with no preservative, or no net on that side).
`conflict`: every net the record could take went to a closer PIC record.
`duplicate`: the record repeats an earlier one (`duplicate_of`) field for
field, so only the earlier one is matched.

```{r}

cruise_ym <- nets |>
```
