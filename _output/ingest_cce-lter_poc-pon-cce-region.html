1 Overview

Source: EDI package knb-lter-cce.104.13 (Aluwihare), entity ParticulateOrganicCarbonandNitrogen (table_104.csv): 3,295 rows, 20 columns, 11 CCE-LTER Process cruises from 2006-05 (P0605KN) to 2024-03 (P2402). Fetched by libs/download_poc_pon_cce_region.R, revision and md5 pinned. Licence: CC0 1.0 (the EML’s intellectualRights).

The companion of cce-lter_poc-pon (EDI 54, Goericke, CalCOFI cruises): same method, same two measurements, but sampled on CCE Process cruises, which follow water parcels (Lagrangian “cycles”, fronts, transects) rather than the CalCOFI station grid.

  • Provider: cce-lter.
  • Grain: one row per water sample. Two kinds:
    • bottle (3,159): a Niskin bottle on a CTD cast, keyed {studyName}-{Cast Number}-{Bottle Number}.
    • underway (57): a surface sample from the ship’s underway intake on P2107 (Sample Type “Underway surface samples”, no bottle, 4 m), keyed {studyName}-uw-{Cast Number}.
  • Realm: env. Two measurements per sample, the same types as cce-lter_poc-pon: poc (C (µmol/L)) and pon (N (µmol/L)), in µmol/L.
  • Not published (kept in the archived source): C (µg/L) and N (µg/L) (the same values in µg/L; conversion asserted), C/N Molar Ratio (ratio of the published values; asserted), Transect, Station, R2R Event, CCE Event (cruise-local labels and event-log ids), Notes and Associative Bottle Number (Q05), Cruise (repeats studyName).
  • Cleaned before publishing (each counted and asserted below):
    • 3 rows that repeat another row in every column are dropped (P1604 cast 29 bottle 16, listed four times; Q02).
    • 2 rows share a sample key but give different depths and times (P1208MV cast 58 bottle 5) and are held out (Q02).
    • 17 rows with no time or no position are held out (P1706; Q03).
    • 57 rows with no depth are held out (Q04).
  • No cruise_key and no site_key. Process cruises are not CalCOFI cruises: they are not in the SWFSC cruise reference, and their stations are not CalCOFI line/stations. Both are NULL on every sample and declared below. grid_key is set where a position falls in a CalCOFI grid cell.
  • No bottle match: calcofi_bottle holds CalCOFI casts only, so there is nothing to match a Process-cruise cast to.

4 Clean, Type-Cast

Four clean-up steps, each counted and asserted against what the source held on 2026-10-06, so a new revision that changes any of them stops the render:

  1. Exact duplicates. P1604 cast 29 bottle 16 (25 m) is listed four times, identical in every column. The 3 copies are dropped (Q02).
  2. Conflicting key. P1208MV cast 58 bottle 5 is listed twice with identical values but at 22 m (CCE event 503, 2012-08-20 23:38) and at 34 m (CCE event 509, 2012-08-21 02:01, the event of every other bottle on cast 58). Both rows are held out until the provider says which is right (Q02).
  3. No time or position. 16 rows on P1706 casts 7 and 58 are dated 0000-00-00 00:00:00 and have no position; 1 row on P1706 cast 941 (SeaSoar1) has a time but no position. All 17 are held out (Q03).
  4. No depth. 57 rows have an empty Depth (m). On every one of those casts the depthless row is the highest bottle number, above the cast’s shallowest depth-labelled bottle, so they are near-surface samples, but depth is a coordinate in the core and is never guessed: they are held out (Q04).

The EML declares NULL as the missing-value code; the file uses empty cells and no NULL or -999 (asserted).

4.1 Derived columns agree with the published ones

The µg/L columns and the molar ratio are not published because they follow from poc and pon. That is checked here: µg/L is µmol/L times the atomic weight (C 12.0107, N 14.0067), and the molar ratio is poc / pon.

Code 
chk <- d_sample |>
  mutate(
    rel_c   = abs(poc_ug_l / 12.0107 - poc_umol_l) / poc_umol_l,
    rel_n   = abs(pon_ug_l / 14.0067 - pon_umol_l) / pon_umol_l,
    rel_cnm = abs(poc_umol_l / pon_umol_l - cn_molar_ratio) / cn_molar_ratio) |>
  summarize(across(starts_with("rel_"), ~ max(.x, na.rm = TRUE)))
chk |> datatable(caption = "Largest relative difference, derived vs published", rownames = FALSE)
Code 
stopifnot(
  "ug/L = umol/L x atomic weight, within 0.1%" = chk$rel_c < 1e-3 && chk$rel_n < 1e-3,
  "C/N molar ratio follows from the published values, within 0.1%" = chk$rel_cnm < 1e-3)

## Overview

**Source**: EDI package `knb-lter-cce.104.13` (Aluwihare), entity
*ParticulateOrganicCarbonandNitrogen* (`table_104.csv`): 3,295 rows, 20 columns,
11 CCE-LTER Process cruises from 2006-05 (P0605KN) to 2024-03 (P2402). Fetched by
`libs/download_poc_pon_cce_region.R`, revision and md5 pinned. Licence: CC0 1.0
(the EML's `intellectualRights`).

The companion of `cce-lter_poc-pon` (EDI 54, Goericke, CalCOFI cruises): same
method, same two measurements, but sampled on CCE **Process** cruises, which follow
water parcels (Lagrangian "cycles", fronts, transects) rather than the CalCOFI
station grid.

- **Provider**: `cce-lter`.
- **Grain**: one row per water sample. Two kinds:
  - `bottle` (3,159): a Niskin bottle on a CTD cast, keyed
    `{studyName}-{Cast Number}-{Bottle Number}`.
  - `underway` (57): a surface sample from the ship's underway intake on P2107
    (`Sample Type` "Underway surface samples", no bottle, 4 m), keyed
    `{studyName}-uw-{Cast Number}`.
- **Realm**: `env`. Two measurements per sample, the same types as
  `cce-lter_poc-pon`: `poc` (`C (µmol/L)`) and `pon` (`N (µmol/L)`), in µmol/L.
- **Not published** (kept in the archived source): `C (µg/L)` and `N (µg/L)` (the
  same values in µg/L; conversion asserted), `C/N Molar Ratio` (ratio of the
  published values; asserted), `Transect`, `Station`, `R2R Event`, `CCE Event`
  (cruise-local labels and event-log ids), `Notes` and `Associative Bottle Number`
  (Q05), `Cruise` (repeats `studyName`).
- **Cleaned before publishing** (each counted and asserted below):
  - 3 rows that repeat another row in every column are dropped (P1604 cast 29
    bottle 16, listed four times; Q02).
  - 2 rows share a sample key but give different depths and times (P1208MV cast
    58 bottle 5) and are held out (Q02).
  - 17 rows with no time or no position are held out (P1706; Q03).
  - 57 rows with no depth are held out (Q04).
- **No cruise_key and no site_key.** Process cruises are not CalCOFI cruises: they
  are not in the SWFSC cruise reference, and their stations are not CalCOFI
  line/stations. Both are NULL on every sample and declared below. `grid_key` is
  set where a position falls in a CalCOFI grid cell.
- **No bottle match**: `calcofi_bottle` holds CalCOFI casts only, so there is
  nothing to match a Process-cruise cast to.

## Clean, Type-Cast

Four clean-up steps, each counted and asserted against what the source held on
2026-10-06, so a new revision that changes any of them stops the render:

1. **Exact duplicates.** P1604 cast 29 bottle 16 (25 m) is listed four times,
   identical in every column. The 3 copies are dropped (Q02).
2. **Conflicting key.** P1208MV cast 58 bottle 5 is listed twice with identical
   values but at 22 m (CCE event 503, 2012-08-20 23:38) and at 34 m (CCE event
   509, 2012-08-21 02:01, the event of every other bottle on cast 58). Both rows
   are held out until the provider says which is right (Q02).
3. **No time or position.** 16 rows on P1706 casts 7 and 58 are dated
   `0000-00-00 00:00:00` and have no position; 1 row on P1706 cast 941 (SeaSoar1)
   has a time but no position. All 17 are held out (Q03).
4. **No depth.** 57 rows have an empty `Depth (m)`. On every one of those casts
   the depthless row is the highest bottle number, above the cast's shallowest
   depth-labelled bottle, so they are near-surface samples, but depth is a
   coordinate in the core and is never guessed: they are held out (Q04).

The EML declares `NULL` as the missing-value code; the file uses empty cells and
no `NULL` or `-999` (asserted).

## Emit Core Tables

Self-contained sample arms via `sample_arm_self()`, one per sample type
(`bottle`, `underway`). Every sample is a root.

```{r}
#| label: emit_core
for (st in c("bottle", "underway")) {
  append_sample(con, sample_arm_self(
    ds_key, glue("(SELECT * FROM poc_sample WHERE core_sample_type = '{st}')"),
    "sample_key_id", st,
    dt_col = "datetime_start_utc", site_expr = "site_key",
    depth_min = "depth_m", depth_max = "depth_m"))
}

append_obs(con, glue("
  SELECT 'env', '{ds_key}',
         '{ds_key}:' || s.core_sample_type || ':' || s.sample_key_id,
         s.grid_key, s.cruise_key, s.latitude, s.longitude,
         CAST(s.datetime_start_utc AS TIMESTAMP), s.depth_m, s.depth_m,
         NULL::VARCHAR, NULL::VARCHAR, m.measurement_type, m.measurement_value,
         NULL::VARCHAR, NULL::DOUBLE
  FROM poc_measurement m
  JOIN poc_sample s USING (sample_id)"))

q1 <- function(sql) dbGetQuery(con, sql)[[1]]
core <- list(
  sample = q1("SELECT COUNT(*) FROM sample"),
  obs    = q1("SELECT COUNT(*) FROM obs"))
cat(glue("core projection -- sample={core$sample} obs={core$obs}"), "\n")

n_exp_obs <- q1("SELECT COUNT(*) FROM poc_measurement")
src_total <- q1("SELECT SUM(measurement_value) FROM poc_measurement")
obs_total <- q1(glue("SELECT SUM(measurement_value) FROM obs WHERE dataset_key = '{ds_key}'"))
stopifnot(
  "one sample per source sample" = core$sample == nrow(d_sample),
  "sample types are bottle (3,159) and underway (57)" =
    q1("SELECT COUNT(*) FROM sample WHERE sample_type = 'underway'") == 57 &&
    q1("SELECT COUNT(*) FROM sample WHERE sample_type = 'bottle'") == 3159,
  "obs is one row per measurement" = core$obs == n_exp_obs,
  "obs value total equals the source" = isTRUE(all.equal(obs_total, src_total)),
  "only poc and pon are emitted" =
    setequal(dbGetQuery(con, glue("SELECT DISTINCT measurement_type FROM obs
                                   WHERE dataset_key = '{ds_key}'"))$measurement_type,
             c("poc", "pon")),
  "sample_key is unique" =
    q1(glue("SELECT COUNT(*) - COUNT(DISTINCT sample_key) FROM sample
             WHERE dataset_key = '{ds_key}'")) == 0,
  "every obs.sample_key resolves in sample" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN sample s USING (sample_key)
        WHERE s.sample_key IS NULL") == 0,
  "every obs.measurement_type resolves in measurement_type" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN measurement_type t USING (measurement_type)
        WHERE t.measurement_type IS NULL") == 0)

# serve the per-dataset name as a VIEW over the core
invisible(dbExecute(con, "DROP TABLE IF EXISTS poc_measurement_src"))
invisible(dbExecute(con, "ALTER TABLE poc_measurement RENAME TO poc_measurement_src"))
invisible(dbExecute(con, glue(
  "CREATE OR REPLACE VIEW poc_measurement AS
   SELECT o.obs_id AS measurement_id,
          o.sample_key,
          regexp_extract(o.sample_key, '^[^:]+:[^:]+:(.*)$', 1) AS sample_key_id,
          o.measurement_type, o.measurement_value, o.measurement_qual
   FROM obs o WHERE o.dataset_key = '{ds_key}'")))
```

### Declared NULLs

`validate_for_release()` treats every `_key` column as required, which is a
heuristic. Each NULL this dataset legitimately carries is declared with its count
and reason; anything undeclared, or a count that moves, stops the render.

```{r}
#| label: validate
results <- validate_for_release(con, checks = "all", strict = FALSE)
cat("validate_for_release:", ifelse(results$passed, "PASSED",
    "reported findings -- reconciled against the declared NULLs below"), "\n")
if (length(results$errors) > 0)
  cat("Errors:\n", paste("-", results$errors, collapse = "\n"), "\n")

n_null <- function(col) q1(glue(
  "SELECT COUNT(*) FROM sample WHERE dataset_key = '{ds_key}' AND {col} IS NULL"))
nullable <- tribble(
  ~table,   ~column,             ~n,                          ~reason,
  "sample", "parent_sample_key", n_null("parent_sample_key"), "single-level dataset: every sample is a root (no calcofi_bottle cast to match on a Process cruise)",
  "sample", "cruise_key",        n_null("cruise_key"),        "CCE Process cruises are not CalCOFI cruises and are not in the SWFSC cruise reference",
  "sample", "site_key",          n_null("site_key"),          "Process-cruise stations are not CalCOFI line/stations",
  "sample", "grid_key",          n_null("grid_key"),          "position outside the CalCOFI grid cells (Process cruises range to 130.5 W)")
nullable |> datatable(caption = "Declared NULLs (count and reason)", rownames = FALSE)

stopifnot(
  "every sample is a root" = nullable$n[nullable$column == "parent_sample_key"] == nrow(d_sample),
  "no sample has a cruise_key or a site_key" =
    n_null("cruise_key") == nrow(d_sample) && n_null("site_key") == nrow(d_sample),
  "no sample lacks a time or a position (held out, Q03)" =
    n_null("datetime") == 0 && n_null("latitude") == 0 && n_null("longitude") == 0,
  "no sample lacks a depth (no-depth rows are held out, Q04)" =
    n_null("depth_max_m") == 0)
# the grid_key NULL count is reported here on the first render; once seen, pin
# it in an assertion so a change is noticed (a ratchet).
```
