1 Overview

Source: NOAA CoastWatch ERDDAP erdCalCOFINOAAhydros (“CalCOFI NOAA Additional CTD”, NOAA SWFSC, Ed Weber), the whole table: 15,151 rows, 14 columns, 1,235 casts on 28 cruise x ship combinations, 2002-02 to 2014-08 (checked 2026-10-06). Values are CTD readings at standard depths (0 to 1,000 m). ERDDAP’s own summary: “oxygen and salinity mostly uncalibrated”.

  • Provider: swfsc (NOAA SWFSC curates it; ERDDAP is only the portal).
  • Grain: sample = one CTD cast, keyed by the source’s own (cruise, ship_code, order_occupied); obs = one value per cast x depth x measurement.
  • Measurements: the uncorrected-sensor types the registry already holds for CTD casts: temperature_1 (degC), salinity_1 (PSU), oxygen_ml_l_1 (ml/L). Not calibrated against bottle samples, which is exactly what those types describe.
  • Not published: percent_saturation (present on 5 cruises only, and derivable from oxygen, temperature and salinity, Q05).
  • Overlap with CalCOFI’s own casts (held out): on some cruises (e.g. 2004-01 David Starr Jordan, 2005-01 New Horizon) these casts are the same casts as calcofi_ctd-cast / calcofi_bottle, at the same station within minutes. The SIO versions are calibrated, so a NOAA cast that matches a CalCOFI cast (same site_key, within 6 h) is held out and only the casts CalCOFI does not already have are published (Q01).
  • Cruise key: ship_code is the ship reference’s own ship_key (NH, JD, SH, …, asserted), and cruise is the YYYYMM designation, so resolve_cruise_key() keys every cast (span, then designation).
Code 
graph LR
  A[ERDDAP erdCalCOFINOAAhydros<br/>15,151 rows] --> B[ctd_cast<br/>one row per cast]
  A --> C[ctd_measurement<br/>long: temperature_1, salinity_1, oxygen_ml_l_1]
  B -.site_key + time.-> D[(calcofi_ctd-cast / calcofi_bottle casts<br/>match = held out)]
  B -.ship_key + cruise.-> E[(cruise_key)]

  C --> G[[core: obs, realm=env]]

6 Casts CalCOFI Already Has (held out)

A NOAA cast that is the same cast as a calcofi_ctd-cast or calcofi_bottle cast is a duplicate of a calibrated SIO record. match_by_site_datetime() finds, for each NOAA cast, the CalCOFI cast at the same site_key on the nearest date (within 1 day), once against the bottle casts and once against the CTD casts: the two CalCOFI datasets can time the same cast hours apart (first render, 2026-10-06: on 2005-01 New Horizon the CTD casts read about 8 h earlier than the bottle casts), and a single match picks only one candidate per date. A cast is held out when either match is within 6 hours. The threshold and the hold-out are Q01.

Code 
ref_tbls <- c(ref_bottle = "calcofi_bottle", ref_ctd_cast = "calcofi_ctd-cast")
for (tbl in names(ref_tbls)) {
  ds <- ref_tbls[[tbl]]
  dbExecute(con, glue("
    CREATE OR REPLACE TABLE {tbl} AS
    SELECT sample_key AS ref_cast_key, site_key, datetime
    FROM read_parquet('{shard_path(ds, 'sample')}')
    WHERE sample_type = 'cast' AND site_key IS NOT NULL AND datetime IS NOT NULL"))
}

match_hours <- function(ref_tbl, fk, hrs) {
  m <- match_by_site_datetime(
    con, "ctd_cast", ref_tbl, fk_col = fk, ref_pk = "ref_cast_key",
    key_col = "site_key", datetime_col = "datetime_start_utc",
    ref_datetime_col = "datetime", window_days = 1)
  dbExecute(con, glue("ALTER TABLE ctd_cast ADD COLUMN IF NOT EXISTS {hrs} DOUBLE"))
  dbExecute(con, glue("
    UPDATE ctd_cast SET {hrs} = ABS(EPOCH(ctd_cast.datetime_start_utc) - EPOCH(r.datetime)) / 3600
    FROM {ref_tbl} r WHERE r.ref_cast_key = ctd_cast.{fk}"))
  m
}

## Overview

**Source**: NOAA CoastWatch ERDDAP `erdCalCOFINOAAhydros` ("CalCOFI NOAA
Additional CTD", NOAA SWFSC, Ed Weber), the whole table: 15,151 rows, 14
columns, 1,235 casts on 28 cruise x ship combinations, 2002-02 to 2014-08
(checked 2026-10-06). Values are CTD readings at standard depths (0 to 1,000 m).
ERDDAP's own summary: "oxygen and salinity mostly uncalibrated".

- **Provider**: `swfsc` (NOAA SWFSC curates it; ERDDAP is only the portal).
- **Grain**: `sample` = one CTD cast, keyed by the source's own
  `(cruise, ship_code, order_occupied)`; `obs` = one value per cast x depth x
  measurement.
- **Measurements**: the uncorrected-sensor types the registry already holds for
  CTD casts: `temperature_1` (degC), `salinity_1` (PSU), `oxygen_ml_l_1` (ml/L).
  Not calibrated against bottle samples, which is exactly what those types
  describe.
- **Not published**: `percent_saturation` (present on 5 cruises only, and
  derivable from oxygen, temperature and salinity, Q05).
- **Overlap with CalCOFI's own casts (held out)**: on some cruises (e.g. 2004-01
  David Starr Jordan, 2005-01 New Horizon) these casts are the same casts as
  `calcofi_ctd-cast` / `calcofi_bottle`, at the same station within minutes. The
  SIO versions are calibrated, so a NOAA cast that matches a CalCOFI cast (same
  `site_key`, within 6 h) is **held out** and only the casts CalCOFI does not
  already have are published (Q01).
- **Cruise key**: `ship_code` is the ship reference's own `ship_key` (NH, JD, SH,
  ..., asserted), and `cruise` is the YYYYMM designation, so
  `resolve_cruise_key()` keys every cast (span, then designation).

## Casts CalCOFI Already Has (held out)

A NOAA cast that is the same cast as a `calcofi_ctd-cast` or `calcofi_bottle`
cast is a duplicate of a calibrated SIO record. `match_by_site_datetime()` finds,
for each NOAA cast, the CalCOFI cast at the same `site_key` on the nearest date
(within 1 day), **once against the bottle casts and once against the CTD casts**:
the two CalCOFI datasets can time the same cast hours apart (first render,
2026-10-06: on 2005-01 New Horizon the CTD casts read about 8 h earlier than the
bottle casts), and a single match picks only one candidate per date. A cast is
held out when either match is within **6 hours**. The threshold and the hold-out
are Q01.

```{r}
#| label: overlap
ref_tbls <- c(ref_bottle = "calcofi_bottle", ref_ctd_cast = "calcofi_ctd-cast")
for (tbl in names(ref_tbls)) {
  ds <- ref_tbls[[tbl]]
  dbExecute(con, glue("
    CREATE OR REPLACE TABLE {tbl} AS
    SELECT sample_key AS ref_cast_key, site_key, datetime
    FROM read_parquet('{shard_path(ds, 'sample')}')
    WHERE sample_type = 'cast' AND site_key IS NOT NULL AND datetime IS NOT NULL"))
}

match_hours <- function(ref_tbl, fk, hrs) {
  m <- match_by_site_datetime(
    con, "ctd_cast", ref_tbl, fk_col = fk, ref_pk = "ref_cast_key",
    key_col = "site_key", datetime_col = "datetime_start_utc",
    ref_datetime_col = "datetime", window_days = 1)
  dbExecute(con, glue("ALTER TABLE ctd_cast ADD COLUMN IF NOT EXISTS {hrs} DOUBLE"))
  dbExecute(con, glue("
    UPDATE ctd_cast SET {hrs} = ABS(EPOCH(ctd_cast.datetime_start_utc) - EPOCH(r.datetime)) / 3600
    FROM {ref_tbl} r WHERE r.ref_cast_key = ctd_cast.{fk}"))
  m
}
m_btl <- match_hours("ref_bottle", "bottle_cast_key", "bottle_hours")
m_ctd <- match_hours("ref_ctd_cast", "ctd_cast_key", "ctd_hours")

dbExecute(con, "ALTER TABLE ctd_cast ADD COLUMN IF NOT EXISTS is_calcofi_dup BOOLEAN")
dbExecute(con, "
  UPDATE ctd_cast SET is_calcofi_dup =
    COALESCE(bottle_hours <= 6, FALSE) OR COALESCE(ctd_hours <= 6, FALSE)")

d_overlap <- dbGetQuery(con, "
  SELECT cruise_ym, ship_code, COUNT(*) AS n_casts,
         SUM(is_calcofi_dup::INT)                 AS n_held_dup,
         COUNT(*) FILTER (WHERE bottle_hours <= 6) AS n_bottle_6h,
         COUNT(*) FILTER (WHERE ctd_hours <= 6)    AS n_ctd_6h,
         COUNT(*) FILTER (WHERE NOT is_calcofi_dup
                           AND (bottle_cast_key IS NOT NULL OR ctd_cast_key IS NOT NULL)) AS n_near_not_dup
  FROM ctd_cast GROUP BY 1, 2 ORDER BY 1, 2")
d_overlap |> datatable(caption = "Casts per cruise that CalCOFI already has (held out, Q01)", rownames = FALSE)

dbGetQuery(con, "
  SELECT cruise_ym, ship_code, COUNT(*) AS n_both,
         ROUND(MEDIAN(ctd_hours - bottle_hours), 1) AS median_ctd_minus_bottle_h
  FROM ctd_cast WHERE bottle_hours IS NOT NULL AND ctd_hours IS NOT NULL
  GROUP BY 1, 2 ORDER BY 1, 2") |>
  datatable(caption = "NOAA casts matched to both CalCOFI datasets: hours to each", rownames = FALSE)

n_dup <- sum(d_overlap$n_held_dup)
n_pub <- nrow(d_cast) - n_dup
```

| `percent_saturation` | -- | **not published** (5 cruises only, derivable, Q05) |
| casts matching a CalCOFI cast | -- | **held out** (Q01) |

## Check Declared Bounds

All three types already carry bounds in the registry (temperature_1 -2 to 40
degC, salinity_1 0 to 45 PSU, oxygen_ml_l_1 0 to 15 ml/L). The suspicious values
the provider is asked about in Q02 (surface salinity of 22 and 24 PSU; oxygen of
12-13 ml/L at 6 degC on 2012-04) are inside those bounds, so nothing is dropped.

```{r}
#| label: bounds-check
bounds_pre <- check_measurement_bounds(con, "ctd_measurement", mt = d_meas_type)
bounds_datatable(bounds_pre)
oob_tally <- drop_out_of_bounds(con, "ctd_measurement", mt = d_meas_type)
cat(glue("out-of-range rows removed: {sum(oob_tally$n_bad %||% 0)}"), "\n")
bounds_post <- check_measurement_bounds(
  con, "ctd_measurement", mt = d_meas_type, include_undeclared = FALSE)
stopifnot(
  "every emitted type has declared bounds" = all(bounds_pre$status != "undeclared"),
  "no value outside a declared bound" = sum(bounds_post$status == "out_of_range") == 0)
```

### Declared NULLs

```{r}
#| label: validate
results <- validate_for_release(con, checks = "all", strict = FALSE)
cat("validate_for_release:", ifelse(results$passed, "PASSED",
    "reported findings -- reconciled against the declared NULLs below"), "\n")
if (length(results$errors) > 0)
  cat("Errors:\n", paste("-", results$errors, collapse = "\n"), "\n")

n_null <- function(col) q1(glue(
  "SELECT COUNT(*) FROM sample WHERE dataset_key = '{ds_key}' AND {col} IS NULL"))
nullable <- tribble(
  ~table,   ~column,             ~n,                          ~reason,
  "sample", "parent_sample_key", n_null("parent_sample_key"), "single-level dataset: every cast is a root",
  "sample", "grid_key",          n_null("grid_key"),          "cast outside the CalCOFI grid (the NOAA cruises off Oregon, Washington and British Columbia)",
  "sample", "site_key",          n_null("site_key"),          "negative line or station number (extended numbering north of the CalCOFI grid): not a CalCOFI station")
nullable |> datatable(caption = "Declared NULLs (count and reason)", rownames = FALSE)
stopifnot(
  "every cast is a root" = nullable$n[nullable$column == "parent_sample_key"] == n_pub,
  "no cast lacks a time or cruise_key" = n_null("datetime") == 0 && n_null("cruise_key") == 0,
  "a NULL site_key only where the line or station is negative" =
    n_null("site_key") == q1("SELECT COUNT(*) FROM ctd_cast_pub WHERE line < 0 OR station < 0"))
```
