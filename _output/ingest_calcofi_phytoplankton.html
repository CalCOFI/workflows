1 Overview

Source: EDI knb-lter-cce.254.4 — Temporal and spatial changes of the abundance and species composition of phytoplankton in the California Current (E. Venrick + CalCOFI + CCE-LTER, 1996-2022). Provider calcofi.

Grain note: samples are pooled across stations into 4 regions before counting, so there is no per-station site_key. We model the native grain — phyto_sample = one row per (cruise × region) — and link to the cruise registry by year-month (cruise_key).

Each region carries a polygon derived from the station membership the source declares, not a position we chose: cc_station_regions() gives every declared station the water nearest to it and dissolves those cells by region, so the four regions tile their pooled domain exactly — no overlap, no gaps, each one connected. The point on phyto_sample is a representative point inside that polygon, which is what replaced the provisional centroid (see Questions Q01).

5 Build Region (polygons from the declared station membership)

The source tells us exactly which CalCOFI stations were pooled into each region — definitions.xlsx sheet Regions, citing Hayward & Venrick 1998 — so read that rather than inventing a position. Membership is all it gives; the geometry is derived from it by calcofi4db::cc_station_regions() (workflows#76 Q01).

# Read the membership verbatim from the source, so a provider correction lands
# by re-running rather than by editing a tribble in this notebook. Rows above
# the "Abbreviation" header are the citation, and the sheet has no column names.

                      col_names = FALSE, .name_repair = "minimal") |>
  setNames(c("region_key", "description", "station_codes"))

  slice((hdr + 1):n()) |>
  filter(!is.na(region_key), !is.na(station_codes)) |>
  mutate(across(everything(), str_squish))

# The sheet writes each station as a ROUNDED-line shorthand plus a station
# number: "87.40" is line 86.7 station 40, NOT line 87.4. Three encodings of one
# grid are in play -- this shorthand, `cc_grid`'s truncated integer (86), and the
# release `grid` table's decimal (86.7) -- and matching the wrong one is silent.

              `87` = 86.7, `90` = 90.0, `93` = 93.3)

  mutate(code = str_split(station_codes, ",")) |>
  select(region_key, code) |> unnest(code) |> mutate(code = str_trim(code)) |>
  mutate(line    = unname(line_map[str_extract(code, "^[0-9]+")]),
         station = as.numeric(str_extract(code, "[0-9]+$")))
stopifnot(
  "every station code parses to a known CalCOFI line" = !anyNA(reg_sta$line),
  "every station code carries a station number"       = !anyNA(reg_sta$station))

# WoRMS aphia_ids resolved + cached in metadata/.../taxon_worms.csv (Q05).
# `species` is the source's name, verbatim (and the name a consumer displays);
# `name_query` is what was looked up; `aphia_id` is the key. Rules (2026-09-28,
# B7 2026-10-01; libs/verify_phyto_aphia.R re-checks them against WoRMS):
# - a clear spelling slip is fixed in the query only (Rhisosolenia -> Rhizosolenia,
#   brightwelli -> brightwellii); the species keys its accepted WoRMS record
# - an unknown species of a named genus -- "sp. 1", "sp. a", "spp.", "uncertain
#   species", a size class, spores, a "complex", a "cf." determination, a species
#   WoRMS does not hold, and species of ONE genus counted together ("A + A. b") --
#   keys that genus. The genus is the ACCEPTED one: where WoRMS files the source's
#   species under another accepted genus the genus codes key that genus, so a
#   hierarchy rollup agrees with the species items ("Ceratium spp." keys Tripos,
#   as the Ceratium species do), while `species` keeps "Ceratium spp."
# - species of two genera counted together key the lowest common ancestor of the
#   two genera in WoRMS's classification (Dactyliosolen + Guinardia ->
#   Rhizosoleniaceae), never a class a family would do instead; Q09 asks the provider
# Calcidiscus leptoporus (worms:235923) and Rhabdosphaera clavigera (worms:235972)

## Overview

**Source**: EDI [`knb-lter-cce.254.4`](https://portal.edirepository.org/nis/mapbrowse?packageid=knb-lter-cce.254.4)
— *Temporal and spatial changes of the abundance and species composition of
phytoplankton in the California Current* (E. Venrick + CalCOFI + CCE-LTER,
1996-2022). Provider `calcofi`.

**Grain note**: samples are **pooled across stations into 4 regions** before
counting, so there is no per-station `site_key`. We model the native grain —
`phyto_sample` = one row per (cruise × region) — and link to the cruise registry
by year-month (`cruise_key`).

Each region carries a **polygon derived from the station membership the source
declares**, not a position we chose: `cc_station_regions()` gives every declared
station the water nearest to it and dissolves those cells by region, so the four
regions tile their pooled domain exactly — no overlap, no gaps, each one
connected. The point on `phyto_sample` is a representative point *inside* that
polygon, which is what replaced the provisional centroid (see Questions Q01).

## Build Region (polygons from the declared station membership)

The source tells us exactly which CalCOFI stations were pooled into each region
— `definitions.xlsx` sheet `Regions`, citing Hayward & Venrick 1998 — so read
that rather than inventing a position. Membership is all it gives; the geometry
is derived from it by `calcofi4db::cc_station_regions()` (workflows#76 Q01).

```{r}
#| label: region

# Read the membership verbatim from the source, so a provider correction lands
# by re-running rather than by editing a tribble in this notebook. Rows above
# the "Abbreviation" header are the citation, and the sheet has no column names.
reg_raw <- read_excel(file.path(dir_dl, "definitions.xlsx"), sheet = "Regions",
                      col_names = FALSE, .name_repair = "minimal") |>
  setNames(c("region_key", "description", "station_codes"))
hdr <- which(str_detect(reg_raw$region_key, regex("^abbreviation$", ignore_case = TRUE)))
stopifnot("`Regions` sheet must carry its Abbreviation header" = length(hdr) == 1)
reg_defs <- reg_raw |>
  slice((hdr + 1):n()) |>
  filter(!is.na(region_key), !is.na(station_codes)) |>
  mutate(across(everything(), str_squish))

# The sheet writes each station as a ROUNDED-line shorthand plus a station
# number: "87.40" is line 86.7 station 40, NOT line 87.4. Three encodings of one
# grid are in play -- this shorthand, `cc_grid`'s truncated integer (86), and the
# release `grid` table's decimal (86.7) -- and matching the wrong one is silent.
line_map <- c(`77` = 76.7, `80` = 80.0, `83` = 83.3,
              `87` = 86.7, `90` = 90.0, `93` = 93.3)
reg_sta <- reg_defs |>
  mutate(code = str_split(station_codes, ",")) |>
  select(region_key, code) |> unnest(code) |> mutate(code = str_trim(code)) |>
  mutate(line    = unname(line_map[str_extract(code, "^[0-9]+")]),
         station = as.numeric(str_extract(code, "[0-9]+$")))
stopifnot(
  "every station code parses to a known CalCOFI line" = !anyNA(reg_sta$line),
  "every station code carries a station number"       = !anyNA(reg_sta$station))

# Positions come from the +proj=calcofi transform, not a `grid` lookup: six of
# the 34 declared stations (83.41, 83.51, 90.37, 77.51, 80.51, 90.53) are
# intermediate inshore stations with no cell in the regularized grid, and a
# lookup drops them with no error. Three of the six are NE's -- the region
# closest to shore, where this dataset's gradient is steepest.
region_sf <- cc_station_regions(reg_sta, group = "region_key")

region <- reg_defs |>
  select(region_key, description, station_codes) |>
  inner_join(st_drop_geometry(region_sf), by = "region_key") |>
  mutate(geom_wkt = st_as_text(st_geometry(region_sf))[match(region_key, region_sf$region_key)]) |>
  select(region_key, description, latitude, longitude, n_stations, station_codes, geom_wkt)
stopifnot(
  "every declared region got geometry" = nrow(region) == nrow(reg_defs),
  "station membership is preserved"    = sum(region$n_stations) == nrow(reg_sta))

# CTAS rather than ALTER + UPDATE: mutating a table that carries a GEOMETRY
# column trips a DuckDB checkpoint bug (see CLAUDE.md).
dbWriteTable(con, "region_wkt", region, overwrite = TRUE)
dbExecute(con, "
  CREATE OR REPLACE TABLE region AS
  SELECT region_key, description, latitude, longitude, n_stations, station_codes,
         ST_GeomFromText(geom_wkt) AS geom
  FROM region_wkt")
dbExecute(con, "DROP TABLE region_wkt")
stopifnot(
  "every region is a single polygon" =
    dbGetQuery(con, "SELECT COUNT(*) FROM region
                     WHERE geom IS NULL OR ST_GeometryType(geom) <> 'POLYGON'")[[1]] == 0)

         "all placed by +proj=calcofi (Q01)"), "\n")
```

```{r}
# - a clear spelling slip is fixed in the query only (Rhisosolenia -> Rhizosolenia,
#   brightwelli -> brightwellii); the species keys its accepted WoRMS record
# - an unknown species of a named genus -- "sp. 1", "sp. a", "spp.", "uncertain
#   species", a size class, spores, a "complex", a "cf." determination, a species
#   WoRMS does not hold, and species of ONE genus counted together ("A + A. b") --
#   keys that genus. The genus is the ACCEPTED one: where WoRMS files the source's
#   species under another accepted genus the genus codes key that genus, so a
#   hierarchy rollup agrees with the species items ("Ceratium spp." keys Tripos,
#   as the Ceratium species do), while `species` keeps "Ceratium spp."
# - species of two genera counted together key the lowest common ancestor of the
#   two genera in WoRMS's classification (Dactyliosolen + Guinardia ->
#   Rhizosoleniaceae), never a class a family would do instead; Q09 asks the provider
# Calcidiscus leptoporus (worms:235923) and Rhabdosphaera clavigera (worms:235972)
# are accepted species the WoRMS name services never return; they are filled from
# their AphiaID records.
worms <- read_csv(here("metadata/calcofi/phytoplankton/taxon_worms.csv")) |>
  mutate(species_code = as.character(species_code))
phyto_taxon <- worms |>
  transmute(species_code, taxa, species,
            aphia_id = as.integer(aphia_id), scientific_name_accepted, rank, kingdom, phylum)
# codes present in the abundance data but absent from the Definitions sheet (Q05):
# add placeholder rows so phyto_measurement.species_code has a complete FK.
missing_codes <- setdiff(unique(d_taxa_long$species_code), phyto_taxon$species_code)
if (length(missing_codes) > 0)
  phyto_taxon <- bind_rows(phyto_taxon, tibble(
    species_code = missing_codes, taxa = "undefined (code not in source definitions; Q05)",
    species = NA_character_, aphia_id = NA_integer_, scientific_name_accepted = NA_character_,
    rank = NA_character_, kingdom = NA_character_, phylum = NA_character_))
dbWriteTable(con, "phyto_taxon", phyto_taxon, overwrite = TRUE)

phyto_meas_src <- d_taxa_long |>
  inner_join(phyto_sample |> select(phyto_sample_id, cruise_yymm, region_key),
             by = c("cruise_yymm", "region" = "region_key")) |>
  filter(!is.na(abundance)) |>
  transmute(phyto_sample_id, cruise_yymm, region_key = region, species_code,
            measurement_type = "phytoplankton_abundance", measurement_value = abundance)

# Duplicate (sample, species_code) rows (workflows#124, WS-1004X) ----
# Two row sets carry the same species code twice in one sample, so a summed
# abundance doubles (a presence count does not):
#  (1) cruises 0704, 1202, 1203 -- 1,496 codes x 4 regions each. 1202 and 1203 sit
#      in both the 1996-2012 and the 2012-2018 workbook (Q06), and the 2007 sheet
#      has two columns both labelled "CalCOFI 0704".
#  (2) species code 178 in 53 further samples (1902-2211): the same row twice.
# Decision (Ben, WS-1004X brief 2026-10-04): where the two rows hold the SAME value, drop the second
# -- the repeat adds nothing. Where they DIFFER, keep both on an explicit allowlist
# until the provider answers Q06: we cannot tell which row is right, and choosing one
# would be inventing a value. The allowlist is keyed by cruise x region x code (a
# phyto_sample_id is a row_number and moves when a cruise is added).
dup_differing <- read_csv(here("metadata/calcofi/phytoplankton/duplicate_pairs_differing.csv"),
                          col_types = cols(.default = "c")) |>
  select(cruise_yymm, region_key, species_code)
n_src_rows    <- nrow(phyto_meas_src)
phyto_measurement <- phyto_meas_src |>
  distinct(phyto_sample_id, species_code, measurement_value, .keep_all = TRUE) |>
  select(-cruise_yymm, -region_key) |>
  mutate(phyto_measurement_id = row_number(), .before = 1)
n_dup_dropped <- n_src_rows - nrow(phyto_measurement)

# uniqueness gate: (phyto_sample_id, species_code) is unique outside the allowlist,
# and the allowlist lists exactly the pairs still duplicated (an entry that no longer
# duplicates must be removed; a new duplicate must fail here, not reach append_obs()).
dup_left <- phyto_measurement |>
  count(phyto_sample_id, species_code) |> filter(n > 1) |>
  inner_join(phyto_sample |> select(phyto_sample_id, cruise_yymm, region_key),
             by = "phyto_sample_id")
stopifnot(
  "(phyto_sample_id, species_code) is not unique outside the Q06 allowlist -- a new duplicate pair" =
    nrow(anti_join(dup_left, dup_differing, by = c("cruise_yymm", "region_key", "species_code"))) == 0,
  "duplicate_pairs_differing.csv lists a pair that is no longer duplicated: remove it" =
    nrow(anti_join(dup_differing, dup_left, by = c("cruise_yymm", "region_key", "species_code"))) == 0,
  "the differing-value pairs left in place must stay the 290 measured at WS-1004X" =
    nrow(dup_left) == 290,
  "identical-value duplicate rows dropped must stay the 4,251 measured at WS-1004X (4,198 pairs + 53 code-178)" =
    n_dup_dropped == 4251)
cat(glue("duplicates: {n_dup_dropped} identical-value repeat rows dropped; ",
         "{nrow(dup_left)} differing pairs kept on the Q06 allowlist"), "\n")
dbWriteTable(con, "phyto_measurement", phyto_measurement, overwrite = TRUE)
cat(glue("phyto_taxon {nrow(phyto_taxon)} ({sum(!is.na(phyto_taxon$aphia_id))} WoRMS-matched); ",
         "phyto_measurement {nrow(phyto_measurement)}"), "\n")

# Codes that reach ONLY a class ----
# A code with no AphiaID in taxon_worms.csv and no ds_taxa_code row in
# metadata/taxon_override.csv falls through to the six ds_common_name rows there
# and keys the class (Bacillariophyceae, Dinophyceae, ...). That is right for the
# source's own unidentified classes ("indistinguished pennate diatoms", "pennate
# sp. 6"); it is wrong for a named taxon whose lookup failed. Until 2026-09-28, 53
# codes were that -- among them both Pseudo-nitzschia size classes, Calcidiscus
# leptoporus and Ditylum brightwellii -- so "Diatoms, not identified further"
# silently absorbed named taxa. A code that keys a class by its AphiaID (rank
# Class: code 77, whose lowest common ancestor IS the class) is the same finding.
# `taxa = "other"` rows are excluded: no class row reaches them; they resolve by
# code override or key dataset-locally (local_allow, below).
ovr_codes <- read_csv(here("metadata/taxon_override.csv"), show_col_types = FALSE) |>
  filter(dataset_key == "calcofi_phytoplankton", match_column == "ds_taxa_code") |>
  pull(match_value) |> as.character()
class_only <- phyto_taxon |>
  filter((is.na(aphia_id) & !species_code %in% ovr_codes) | rank %in% "Class",
         !is.na(species), taxa != "other") |>
  select(species_code, taxa, species)
# the allowlist: ONE code at a time, with the reason. Sixteen are the source's own
# unidentified classes; code 77 counts a named Mastogloia with an unidentified
# pennate, whose lowest common ancestor is the class. A named taxon that fails its
# lookup is not on this list, so it fails the render instead of vanishing into a class.
class_allow <- tibble::tribble(
  ~species_code, ~why,
  "603", "source's own unidentified class: indistinguished diatom species",
  "85",  "source's own unidentified class: pennate sp. 1",
  "243", "source's own unidentified class: pennate sp. 2",
  "318", "source's own unidentified class: pennate sp. 3",
  "401", "source's own unidentified class: pennate sp. 4",
  "508", "source's own unidentified class: pennate sp. 5",
  "512", "source's own unidentified class: pennate sp. 6",
  "608", "source's own unidentified class: indistinguished pennate diatoms",
  "615", "source's own unidentified class: indistinguished thecate dinoflagellates",
  "616", "source's own unidentified class: indistinguished athecate dinoflagellates",
  "224", "source's own unidentified class: coccolithophore sp. 1",
  "225", "source's own unidentified class: coccolithophore sp. 2",
  "332", "source's own unidentified class: coccolithophore sp. 3",
  "222", "source's own unidentified class: coccolithophore sp. 4",
  "617", "source's own unidentified class: indistinguished coccolithophore spp.",
  "602", "source's own unidentified class: indistinguished silicoflagellate spp.",
  "77",  "two-genus entry (Mastogloia woodiana + pennate a): lowest common ancestor is the class (Q09)")
cat(glue("{nrow(class_only)} codes key only a class; {nrow(class_allow)} allowlisted"), "\n")
datatable(class_only |> left_join(class_allow, by = "species_code"), caption = paste(
  "Codes keyed only to a class. Every one must be allowlisted: the source's own",
  "unidentified classes, and the two-genus entry whose common ancestor is the class."))
stopifnot(
  "a named code keys only its class: fix its lookup in taxon_worms.csv, or allowlist it with a reason" =
    length(setdiff(class_only$species_code, class_allow$species_code)) == 0,
```

## Emit Core Tables

Project this dataset into the shared consolidated core model
(`design_env-bio-consolidation.md`). These core tables **are** this ingest's
output: `release_database.qmd` concatenates the per-dataset shards rather than
re-deriving the core, so there is exactly one projection to keep correct.

This dataset is **region-pooled**: the grain is cruise × region, not station ×
time, so `sample_type = 'region_pool'` and both `grid_key` and `datetime` are
NULL *by design*. The usual `WHERE grid_key IS NOT NULL` guard every other arm
carries must therefore **not** be applied here, or every row is dropped.

```{r}
  FROM phyto_taxon ORDER BY species_code")
```
