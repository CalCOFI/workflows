1 Overview

Source: SWFSC’s CSV export of its CalCOFI database — Cufes.csv in the provider folder swfsc/ichthyo/ (Ed Weber, NOAA SWFSC, 2026-09-26: “I also added it to the csv repo. Cufes is also now linked with CruiseId”). One row per Continuous Underway Fish Egg Sampler (CUFES) sample: start and stop time and position, underway temperature, salinity, wind and pump speed, and the egg counts of sardine, anchovy, jack mackerel, hake, squid and other fish. Provider swfsc.

Until 2026-10-04 this ingest read NOAA CoastWatch ERDDAP erdCalCOFIcufes. Compared record by record (WS-1004Z), the CSV holds 47,989 of ERDDAP’s 49,572 samples, with the same time span (1996-03-15 to 2022-04-27), identical egg counts and start/stop times, and positions and environment equal to within float rounding (≤ 1.5e-5). The 1,583 ERDDAP-only samples are the ones Ed removed at source (questions Q04): 1,563 with no position at either end — three whole cruises among them, 199809NH, 199908NH and 200001NH — and 20 with a stop position only (Q09). So the CSV supersedes ERDDAP; nothing it lacks is a sample anyone can place, and ERDDAP is no longer read.

What the export adds: the provider’s own CufesId (released as sample.source_uuid, and the id in sample_key), the CruiseId link to the cruise reference (so every sample keys its cruise by the provider’s own link rather than by date), and Ed’s answers on units and standardization (Q01, Q02, Q05), applied below as the egg_concentration measurement type (eggs per m³ pumped).

4 Build Sample + Measurement Tables

Code 
# A CUFES sample is a SEGMENT, not a point: the pump runs while the ship steams,
# and the source records where the sample started and where it stopped. Those
# ends are a median 8.71 km apart, so the start position alone — from which
# `grid_key` and `hex_id` are derived — would report a point ~4.4 km from the
# sample's centre. The position is the MIDPOINT of the segment; the ends stay as
# `start_latitude`/`start_longitude` and `stop_latitude`/`stop_longitude`.
#
# A position is a PAIR: choose the SOURCE first — midpoint, else start, else stop
# — and require both components of that source to be real (NaN passes IS NOT
# NULL, so it is tested explicitly). Since SWFSC removed the records with no start
# position at source (questions Q04), every sample of this export has a start;
# 37 have no stop and take the start.
#
# Effort, per Ed Weber (SWFSC, 2026-09-25, questions Q01/Q02/Q05): minutes sampled
# = stop - start; pump speed is m3/min and the sample's is the mean of its two
# ends; the standardization is defined only where the minutes and both pump
# speeds are positive (anything else gets no concentration, counted below).
# Both rules live in libs/cufes.R, asserted by tests/testthat/test-cufes.R.
source(here("libs/cufes.R"))
ok <- function(x) !is.na(x) & !is.nan(x) & is.finite(x)
d <- bind_cols(
  d,
  cufes_position(d$start_latitude, d$start_longitude, d$stop_latitude, d$stop_longitude),
  cufes_effort(d$datetime_start_utc, d$datetime_end_utc, d$start_pump_speed, d$stop_pump_speed))

stopifnot(
  "latitude and longitude must be present together or not at all" =
    sum(ok(d$latitude) != ok(d$longitude)) == 0)
d |> count(position_source) |>
  datatable(caption = "Which ends of the segment give each sample's position")

6 Add Measurement Types

The six raw counts publish as abundance (units count), as before. The concentration is its own type, egg_concentration, in eggs per m³ of water pumped. Its bound is one-sided (valid_min = 0, a concentration is never negative); there is no ceiling to declare without inventing one.

Code 
d_meas_type <- register_measurement_types(
  tibble(
    measurement_type = "egg_concentration",
    description      = paste(
      "Fish or squid eggs per cubic metre of water pumped by the Continuous Underway",
      "Fish Egg Sampler (CUFES): the sample's egg count standardized by its minutes",
      "sampled and its mean pump speed"),
    units            = "count/m3",
    valid_min        = 0,
    derivation       = paste0(
      "Ed Weber (SWFSC), 2026-09-25, swfsc_cufes questions Q01: \"The standardization is ",
      "usually: eggs / m^3 = (count / minutes sampled) / mean pump speed, i.e., eggs / m^3 = ",
      "(count / (stop time - start time) / ((start pump speed + stop pump speed) / 2)\". ",
      "Computed in ingest_swfsc_cufes.qmd from Cufes.csv: Stop - Start in minutes, the mean of ",
      "StartPumpSpeed and StopPumpSpeed (m3/min, Q02); only where the minutes and both pump ",
      "speeds are present and positive."),
    is_canonical     = TRUE,

7 Emit Core Tables

Project this dataset into the shared consolidated core model (design_env-bio-consolidation.md). These core tables are this ingest’s output: release_database.qmd concatenates the per-dataset shards rather than re-deriving the core, so there is exactly one projection to keep correct.

CUFES bakes the taxon into the measurement name (sardine_eggs, sardine_eggs_per_m3, …). metadata/measurement_taxon.csv decomposes each raw name into a real taxon_key, the canonical measurement_type (abundance or egg_concentration) and life_stage (egg), so both land in obs as ordinary taxon-resolved occurrences. The taxa are the export’s own: each crosswalk row’s worms_id/itis_id is asserted equal to the AphiaId/Tsn that SWFSC’s Species.csv gives the same scientific name.

## Overview

**Source**: SWFSC's CSV export of its CalCOFI database — `Cufes.csv` in the
provider folder `swfsc/ichthyo/` (Ed Weber, NOAA SWFSC, 2026-09-26: "I also added
it to the csv repo. Cufes is also now linked with CruiseId"). One row per
Continuous Underway Fish Egg Sampler (CUFES) sample: start and stop time and
position, underway temperature, salinity, wind and pump speed, and the egg counts
of sardine, anchovy, jack mackerel, hake, squid and other fish. Provider `swfsc`.

**Until 2026-10-04 this ingest read NOAA CoastWatch ERDDAP `erdCalCOFIcufes`.**
Compared record by record (WS-1004Z), the CSV holds 47,989 of ERDDAP's 49,572
samples, with the same time span (1996-03-15 to 2022-04-27), identical egg counts
and start/stop times, and positions and environment equal to within float
rounding (≤ 1.5e-5). The 1,583 ERDDAP-only samples are the ones Ed removed at
source (questions Q04): 1,563 with no position at either end — three whole
cruises among them, 199809NH, 199908NH and 200001NH — and 20 with a stop position
only (Q09). So the CSV supersedes ERDDAP; nothing it lacks is a sample anyone can
place, and ERDDAP is no longer read.

What the export adds: the provider's own `CufesId` (released as
`sample.source_uuid`, and the id in `sample_key`), the `CruiseId` link to the
cruise reference (so every sample keys its cruise by the provider's own link
rather than by date), and Ed's answers on units and standardization (Q01, Q02,
Q05), applied below as the `egg_concentration` measurement type (eggs per m³
pumped).

## Build Sample + Measurement Tables

```{r}
#| label: build

# A CUFES sample is a SEGMENT, not a point: the pump runs while the ship steams,
# and the source records where the sample started and where it stopped. Those
# ends are a median 8.71 km apart, so the start position alone — from which
# `grid_key` and `hex_id` are derived — would report a point ~4.4 km from the
# sample's centre. The position is the MIDPOINT of the segment; the ends stay as
# `start_latitude`/`start_longitude` and `stop_latitude`/`stop_longitude`.
#
# A position is a PAIR: choose the SOURCE first — midpoint, else start, else stop
# — and require both components of that source to be real (NaN passes IS NOT
# NULL, so it is tested explicitly). Since SWFSC removed the records with no start
# position at source (questions Q04), every sample of this export has a start;
# 37 have no stop and take the start.
#
# Effort, per Ed Weber (SWFSC, 2026-09-25, questions Q01/Q02/Q05): minutes sampled
# = stop - start; pump speed is m3/min and the sample's is the mean of its two
# ends; the standardization is defined only where the minutes and both pump
# speeds are positive (anything else gets no concentration, counted below).
# Both rules live in libs/cufes.R, asserted by tests/testthat/test-cufes.R.
source(here("libs/cufes.R"))
ok <- function(x) !is.na(x) & !is.nan(x) & is.finite(x)
d <- bind_cols(
  d,
  cufes_position(d$start_latitude, d$start_longitude, d$stop_latitude, d$stop_longitude),
  cufes_effort(d$datetime_start_utc, d$datetime_end_utc, d$start_pump_speed, d$stop_pump_speed))

stopifnot(
  "latitude and longitude must be present together or not at all" =
    sum(ok(d$latitude) != ok(d$longitude)) == 0)
d |> count(position_source) |>
  datatable(caption = "Which ends of the segment give each sample's position")

egg_cols <- c("sardine_eggs", "anchovy_eggs", "jack_mackerel_eggs",
              "hake_eggs", "squid_eggs", "other_fish_eggs")
d_cufes <- d |> select(-all_of(egg_cols), -conc_ok)
dbWriteTable(con, "cufes", d_cufes, overwrite = TRUE)
invisible(dbExecute(con, "ALTER TABLE cufes ALTER cufes_uuid TYPE UUID"))
invisible(dbExecute(con, "ALTER TABLE cufes ALTER cruise_uuid TYPE UUID"))

# raw egg counts, long; an empty cell is "not counted", so it is no row
d_cnt <- d |>
  select(cufes_uuid, all_of(egg_cols)) |>
  pivot_longer(all_of(egg_cols), names_to = "measurement_type", values_to = "measurement_value") |>
  filter(!is.na(measurement_value)) |>
  mutate(measurement_value = as.double(measurement_value))

# eggs/m3 = (count / minutes sampled) / mean pump speed (Ed Weber, Q01), one row
# per count whose sample has positive minutes and pump speeds
d_conc <- d_cnt |>
  inner_join(d |> filter(conc_ok) |> select(cufes_uuid, duration_min, pump_speed_mean),
             by = "cufes_uuid") |>
  mutate(
    measurement_type  = paste0(measurement_type, "_per_m3"),
    measurement_value = cufes_egg_concentration(
      measurement_value, duration_min, pump_speed_mean, conc_ok = TRUE)) |>
  select(cufes_uuid, measurement_type, measurement_value)

d_meas <- bind_rows(d_cnt, d_conc) |>
  mutate(measurement_qual = NA_character_) |>
  mutate(cufes_measurement_id = row_number(), .before = 1)
dbWriteTable(con, "cufes_measurement", d_meas, overwrite = TRUE)
invisible(dbExecute(con, "ALTER TABLE cufes_measurement ALTER cufes_uuid TYPE UUID"))

n_no_conc <- sum(!d$conc_ok)
cat(glue(
  "cufes {format(nrow(d_cufes), big.mark = ',')} samples; ",
  "{format(nrow(d_cnt), big.mark = ',')} egg counts; ",
  "{format(nrow(d_conc), big.mark = ',')} egg concentrations over ",
  "{format(sum(d$conc_ok), big.mark = ',')} samples; ",
  "{n_no_conc} sample(s) with no positive minutes / pump speeds get none"), "\n")
stopifnot(
  "every count of a sample with positive effort must get its concentration" =
    nrow(d_conc) == sum(d_cnt$cufes_uuid %in% d$cufes_uuid[d$conc_ok]))

# effort inputs worth a provider's look: a pump speed that changes more than
# two-fold within one sample (questions Q10) and samples under a minute
d |>
  filter(stop_pump_speed / start_pump_speed > 2 | stop_pump_speed / start_pump_speed < 0.5 |
           duration_min < 1) |>
  select(cruise, ship_key, sample_number, datetime_start_utc, datetime_end_utc,
         duration_min, start_pump_speed, stop_pump_speed, volume_pumped_m3) |>
  datatable(caption = "Effort inputs to check: pump speed changing > 2x within a sample (Q10), or under a minute sampled")
```

## Resolve Keys + Spatial

`cruise_key` comes from the cruise reference through the provider's own link,
`CruiseId` → `cruise.cruise_uuid` (method `cruise_uuid`). The reference is the
`cruise` shard `ingest_swfsc_ichthyo.qmd` stages from the same export's
`Cruise.csv`, so it knows every `CruiseId` this file names. The date-span rule
(`resolve_cruise_key()`: span, then the source's own `Cruise` designation, then the
month) is run beside it as a check, and is what keys any sample whose `CruiseId`
the reference lacks.

```{r}
  SELECT cufes_uuid, ship_key, cruise, datetime_start_utc AS datetime FROM cufes"))

  UPDATE cufes SET cruise_key = z.cruise_key, cruise_key_method = z.cruise_key_method
  FROM zk z WHERE cufes.cufes_uuid = z.cufes_uuid AND cufes.cruise_key IS NULL")
n_disagree <- sum(d_ck$n_samples[d_ck$comparison == "disagree"])
cat(glue(
  "cruise_key by span/source for CruiseIds the reference lacks: {n_by_span}; ",
  "CruiseId and date span disagree on {n_disagree} sample(s) (the CruiseId key is kept: ",
  "the reference wins)"), "\n")
invisible(dbExecute(con, "DROP TABLE zk"))

# the sample's date inside its cruise's observed span (the release gate's
# tolerance is 31 days; report against the 3-day span-match tolerance)
d_span <- dbGetQuery(con, "
  SELECT COUNT(*) FILTER (WHERE c.date_min IS NULL) AS n_cruise_no_span,
         COUNT(*) FILTER (WHERE CAST(u.datetime_start_utc AS DATE) NOT BETWEEN
                                c.date_min - 3 AND c.date_max + 3)  AS n_outside_3d,
         COUNT(*) FILTER (WHERE CAST(u.datetime_start_utc AS DATE) NOT BETWEEN
                                c.date_min - 31 AND c.date_max + 31) AS n_outside_31d
  FROM cufes u JOIN cruise c USING (cruise_key)")
n_ck_null <- dbGetQuery(con, "SELECT COUNT(*) FROM cufes WHERE cruise_key IS NULL")[[1]]
cat(glue(
  "cruise_key: {format(nrow(d_cufes) - n_ck_null, big.mark = ',')}/{format(nrow(d_cufes), big.mark = ',')} samples; ",
  "{n_ck_null} NULL; samples outside their cruise's tow span: ",
  "{d_span$n_outside_3d} beyond 3 days, {d_span$n_outside_31d} beyond 31 days ",
  "({d_span$n_cruise_no_span} on a cruise with no tow span)"), "\n")

add_point_geom(con, "cufes", lon_col = "longitude", lat_col = "latitude")
assign_grid_key(con, "cufes") |> datatable(caption = "Grid assignment")
```

## Add Measurement Types

The six raw counts publish as `abundance` (units `count`), as before. The
concentration is its own type, `egg_concentration`, in eggs per m³ of water
pumped. Its bound is one-sided (`valid_min = 0`, a concentration is never
negative); there is no ceiling to declare without inventing one.

```{r}
#| label: meas-types

d_meas_type <- register_measurement_types(
  tibble(
    measurement_type = "egg_concentration",
    description      = paste(
      "Fish or squid eggs per cubic metre of water pumped by the Continuous Underway",
      "Fish Egg Sampler (CUFES): the sample's egg count standardized by its minutes",
      "sampled and its mean pump speed"),
    units            = "count/m3",
    valid_min        = 0,
    derivation       = paste0(
      "Ed Weber (SWFSC), 2026-09-25, swfsc_cufes questions Q01: \"The standardization is ",
      "usually: eggs / m^3 = (count / minutes sampled) / mean pump speed, i.e., eggs / m^3 = ",
      "(count / (stop time - start time) / ((start pump speed + stop pump speed) / 2)\". ",
      "Computed in ingest_swfsc_cufes.qmd from Cufes.csv: Stop - Start in minutes, the mean of ",
      "StartPumpSpeed and StopPumpSpeed (m3/min, Q02); only where the minutes and both pump ",
      "speeds are present and positive."),
    is_canonical     = TRUE,
    `_source_column` = paste(paste0(egg_cols, "_per_m3"), collapse = "; "),
    `_source_table`  = "cufes_measurement",
    `_source_datasets` = ds_key,
    grain            = "obs",
    denominator      = "volume",
```

## Emit Core Tables

Project this dataset into the shared consolidated core model
(`design_env-bio-consolidation.md`). These core tables **are** this ingest's
output: `release_database.qmd` concatenates the per-dataset shards rather than
re-deriving the core, so there is exactly one projection to keep correct.

CUFES bakes the taxon into the measurement name (`sardine_eggs`,
`sardine_eggs_per_m3`, …). `metadata/measurement_taxon.csv` decomposes each raw
name into a real `taxon_key`, the canonical `measurement_type` (`abundance` or
`egg_concentration`) and `life_stage` (`egg`), so both land in `obs` as ordinary
taxon-resolved occurrences. The taxa are the export's own: each crosswalk row's
`worms_id`/`itis_id` is asserted equal to the `AphiaId`/`Tsn` that SWFSC's
`Species.csv` gives the same scientific name.

```{r}
#| label: emit_core

# filter the crosswalk to THIS dataset -- an unfiltered read leaks other datasets'
# taxa into this shard
mt_taxon <- read_csv(here("metadata/measurement_taxon.csv"),
                     col_types = cols(worms_id = "i", itis_id = "i",
                                      bin_value = "d", .default = "c")) |>
  filter(dataset_key == ds_key)
tx_over  <- read_csv(here("metadata/taxon_override.csv"), show_col_types = FALSE)

# the source's own ids: Species.csv of the same export (read-only)
d_species <- read_csv(path_expand(glue("{dir_data}/swfsc/ichthyo/Species.csv")),
                      col_types = cols(.default = "c")) |>
  transmute(taxon_scientific_name = Taxon,
            aphia_src = as.integer(AphiaId), tsn_src = as.integer(Tsn))
d_tx_chk <- mt_taxon |> distinct(taxon_scientific_name, worms_id, itis_id) |>
  left_join(d_species, by = "taxon_scientific_name")
d_tx_chk |> datatable(caption = "CUFES taxa: crosswalk ids versus SWFSC Species.csv")
stopifnot(
  "every CUFES taxon must be in SWFSC's Species.csv with the crosswalk's AphiaID and TSN" =
    all(d_tx_chk$worms_id == d_tx_chk$aphia_src & d_tx_chk$itis_id == d_tx_chk$tsn_src,
        na.rm = FALSE))

# cross-reference, lineage, then the references -- the order the taxon-reference
# skill sets (the composite-measurement path: no dataset_taxon staging)
ensure_taxon_xref(con, mt_taxon, tx_over,
                  cache_csv = here("metadata/taxon_xref.csv"))
ensure_taxon_lineage(con, mt_taxon, tx_over,
                     cache_csv = here("metadata/taxon_lineage.csv"))
n_taxon    <- build_taxon_reference(con, mt_taxon, tx_over)
n_ds_taxon <- resolve_dataset_taxon(con, mt_taxon, tx_over)
# stage the crosswalk WITH its derived taxon_key (never a 'worms:' || id string)
ensure_measurement_taxon(con, mt_taxon, dataset_key = ds_key)

# sample: one underway row per CUFES sample, keyed on SWFSC's CufesId, which also
# ships as source_uuid. site_key stays NULL: CUFES samples are "not constrained to
# have any relation with CalCOFI stations" (Ed Weber, Q04).
append_sample(con, glue("
  SELECT {ns_key(ds_key, 'underway', 'u.cufes_uuid')} AS sample_key, 'underway' AS sample_type,
         NULL::VARCHAR AS parent_sample_key,
         {ns_key(ds_key, 'underway', 'u.cufes_uuid')} AS root_sample_key,
         '{ds_key}' AS dataset_key,
         u.grid_key, NULL::VARCHAR AS site_key, u.cruise_key, NULL::INTEGER AS order_occ,
         u.latitude, u.longitude, CAST(u.datetime_start_utc AS TIMESTAMP) AS datetime,
         0::DOUBLE AS depth_min_m, 0::DOUBLE AS depth_max_m,
         NULL::VARCHAR AS tow_type,
         NULL::VARCHAR AS data_stage,
         u.cufes_uuid AS source_uuid
  FROM cufes u"))

append_obs(con, glue("
  SELECT 'bio', '{ds_key}', {ns_key(ds_key, 'underway', 'u.cufes_uuid')},
         u.grid_key, u.cruise_key, u.latitude, u.longitude,
         CAST(u.datetime_start_utc AS TIMESTAMP), 0::DOUBLE, 0::DOUBLE,
         mx.taxon_key, mx.life_stage, mx.measurement_type, m.measurement_value,
         m.measurement_qual, NULL::DOUBLE
  FROM cufes_measurement m JOIN cufes u USING (cufes_uuid)
  JOIN _measurement_taxon mx ON mx.dataset_key = '{ds_key}'
                            AND mx.raw_measurement_type = m.measurement_type
                            AND mx.target = 'obs'"))

core <- list(
  sample        = dbGetQuery(con, "SELECT COUNT(*) FROM sample")[[1]],
  obs           = dbGetQuery(con, "SELECT COUNT(*) FROM obs")[[1]],
  taxon         = n_taxon,
  dataset_taxon = n_ds_taxon)
cat(glue(
  "core projection — sample={core$sample %||% 0} obs={core$obs %||% 0} ",
  "taxon={core$taxon %||% 0} dataset_taxon={core$dataset_taxon %||% 0}\n"))

# every measurement whose raw type is registered must reach obs with a real
# taxon_key -- an unregistered raw type is dropped by the INNER join, so assert
# the registry covers the vocabulary in the data
n_obs <- dbGetQuery(con, "SELECT COUNT(*) FROM obs")[[1]]
n_unreg <- dbGetQuery(con, "
  SELECT COUNT(DISTINCT m.measurement_type) FROM cufes_measurement m
  WHERE m.measurement_type NOT IN (
    SELECT raw_measurement_type FROM _measurement_taxon WHERE target = 'obs')")[[1]]
stopifnot(
  "obs must be one row per measurement" = n_obs == nrow(d_meas),
  "every cufes measurement_type must be in measurement_taxon.csv" = n_unreg == 0,
  "cufes obs must all carry a taxon_key" =
    dbGetQuery(con, "SELECT COUNT(*) FROM obs WHERE taxon_key IS NULL")[[1]] == 0,
  "sample_key must be unique" =
    dbGetQuery(con, "SELECT COUNT(*) - COUNT(DISTINCT sample_key) FROM sample")[[1]] == 0,
  "every obs.sample_key must resolve in sample" =
    dbGetQuery(con, "SELECT COUNT(*) FROM obs o LEFT JOIN sample s USING (sample_key)
                     WHERE s.sample_key IS NULL")[[1]] == 0)
dbGetQuery(con, "
  SELECT measurement_type, COUNT(*) AS n_rows, COUNT(DISTINCT taxon_key) AS n_taxa,
         MIN(measurement_value) AS v_min, MAX(measurement_value) AS v_max
  FROM obs GROUP BY 1 ORDER BY 1") |>
  datatable(caption = "obs by measurement_type")
cat(glue("obs parity: {format(n_obs, big.mark = ',')} rows, all taxon-resolved"), "\n")
```
