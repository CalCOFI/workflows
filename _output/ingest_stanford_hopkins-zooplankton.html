1 Overview

Source: Whitmire, A. L. (2022). Monterey Bay zooplankton data from the Hopkins Marine Station CalCOFI program (1955-1963). Stanford Digital Repository, doi:10.25740/nt620vn7810, CC0. 18 CSVs (zooplankton-data-sheets-{year}_{1,2}.csv), the README and a PDF of the methods notes and example log sheets, under data-public/stanford/hopkins-zooplankton/. Provider stanford (Hopkins Marine Station; the Miller Library curates the archive).

What a row is: one log sheet = one sampling day, with columns for six fixed stations in Monterey Bay. For each station the sheet records the wet settled volume (mL) of a half-metre net sample (towed obliquely from 15 m) and, for each of 24 printed taxa or groups, the share of that volume it made up, estimated by eye. Two extra rows are hand-written taxa.

Why it needs a parse step (libs/parse_stanford_hopkins-zooplankton.R):

  • Every sheet was transcribed twice, independently, by FromThePage volunteers. The parse pairs the two by page position and keeps a value only where they agree, or only one of them transcribed the cell (flagged single_transcription). Cells where they disagree are withheld and listed for a check against the scans (Q06).
  • Count and percent were merged. The sheet has separate No. and % rows per taxon; the transcription template had one cell. Counts were only recorded for five or fewer individuals, so a value above 5 is a percent, but a whole number 1-5 is ambiguous. Those are published with measurement_qual = 'unit_unclear' (Q01).
  • Dates are written four ways: 10-II-55 (as on the sheet), 4/2/55 (day-first), 2/7/61 (US month-first, for 7-II-61) and 14.VII.59. The Roman-numeral form is trusted first; a slash date is read whichever way matches the other transcription.
  • Text values: “trace”, “<1”, “no haul”, “fouled”, “-”, and Excel-mangled cells (“4-Feb”). Only numbers reach the core (Q02, Q04).

8 Measurement Vocabulary + Dataset Metadata

Two quantities:

  • settled_volume_ml, already registered (by cdfw_dungeness-crab), for the wet settled volume, at the sample level;
  • percent_volume, new in this change, for each taxon’s share of that volume, at the obs level. Bounded 0-100.

The taxon lives in taxon_key, never in the type name: the 24 printed rows map to (measurement_type = percent_volume, taxon_key, life_stage) through metadata/measurement_taxon.csv. The quality codes (unit_unclear, single_transcription) are registered in metadata/measurement_qual.csv under code set hopkins-zooplankton.

9 Emit Core Tables

Project into the shared core (RUNBOOK.md §3b) with the generic append_* helpers; no calcofi4db change is needed.

  • sample: one tow per emitted sheet x station, keyed stanford_hopkins-zooplankton:tow:{year}-{page_position}-{station}, depth 0-15 m, no parent. cruise_key and site_key are NULL: these were Hopkins day trips, not CalCOFI ship cruises, and the six stations are not on the CalCOFI line/station pattern (Q08). The date carries no time of day, so datetime is midnight of the sample date.
  • obs: one row per numeric taxon cell (log-sheet rows 1-24) on an emitted tow. measurement_qual is NULL where both transcriptions agree and the value is unambiguous, else unit_unclear, single_transcription, or both.
  • sample_measurement: the wet settled volume where it is a number.
  • Not published (kept in the archived source and the check list): cells the transcriptions disagree on, “trace” / “<1” (Q02), dashes and unparsed text (Q04), the hand-written rows 25 and bottom (Q05), and absences (Q03).

  "one core sample per emitted tow" = core_n$sample == n_emit,
  "sample_key must be unique" =
    q1("SELECT COUNT(*) - COUNT(DISTINCT sample_key) FROM sample") == 0,
  "obs must carry every emitted source cell, no more" = core_n$obs == nrow(src_obs),

    isTRUE(all.equal(q1("SELECT SUM(measurement_value) FROM obs"), sum(src_obs$value))),

        WHERE s.sample_key IS NULL") == 0,

## Overview

**Source**: Whitmire, A. L. (2022). *Monterey Bay zooplankton data from the
Hopkins Marine Station CalCOFI program (1955-1963)*. Stanford Digital Repository,
[doi:10.25740/nt620vn7810](https://doi.org/10.25740/nt620vn7810), CC0. 18 CSVs
(`zooplankton-data-sheets-{year}_{1,2}.csv`), the README and a PDF of the methods
notes and example log sheets, under `data-public/stanford/hopkins-zooplankton/`.
Provider `stanford` (Hopkins Marine Station; the Miller Library curates the
archive).

**What a row is**: one log sheet = one sampling day, with columns for six fixed
stations in Monterey Bay. For each station the sheet records the **wet settled
volume** (mL) of a half-metre net sample (towed obliquely from 15 m) and, for each
of 24 printed taxa or groups, **the share of that volume** it made up, estimated
by eye. Two extra rows are hand-written taxa.

**Why it needs a parse step** (`libs/parse_stanford_hopkins-zooplankton.R`):

- **Every sheet was transcribed twice**, independently, by FromThePage
  volunteers. The parse pairs the two by page position and keeps a value only
  where they agree, or only one of them transcribed the cell (flagged
  `single_transcription`). Cells where they disagree are withheld and listed for
  a check against the scans (Q06).
- **Count and percent were merged.** The sheet has separate *No.* and *%* rows
  per taxon; the transcription template had one cell. Counts were only recorded
  for five or fewer individuals, so a value above 5 is a percent, but a whole
  number 1-5 is ambiguous. Those are published with
  `measurement_qual = 'unit_unclear'` (Q01).
- **Dates are written four ways**: `10-II-55` (as on the sheet), `4/2/55`
  (day-first), `2/7/61` (US month-first, for 7-II-61) and `14.VII.59`. The
  Roman-numeral form is trusted first; a slash date is read whichever way matches
  the other transcription.
- **Text values**: "trace", "<1", "no haul", "fouled", "-", and Excel-mangled
  cells ("4-Feb"). Only numbers reach the core (Q02, Q04).

## Emit Core Tables

Project into the shared core (`RUNBOOK.md` §3b) with the generic `append_*`
helpers; no `calcofi4db` change is needed.

- **`sample`**: one `tow` per emitted sheet x station, keyed
  `stanford_hopkins-zooplankton:tow:{year}-{page_position}-{station}`, depth
  0-15 m, no parent. `cruise_key` and `site_key` are NULL: these were Hopkins
  day trips, not CalCOFI ship cruises, and the six stations are not on the CalCOFI
  line/station pattern (Q08). The date carries no time of day, so `datetime` is
  midnight of the sample date.
- **`obs`**: one row per numeric taxon cell (log-sheet rows 1-24) on an emitted
  tow. `measurement_qual` is NULL where both transcriptions agree and the value is
  unambiguous, else `unit_unclear`, `single_transcription`, or both.
- **`sample_measurement`**: the wet settled volume where it is a number.
- **Not published** (kept in the archived source and the check list): cells the
  transcriptions disagree on, "trace" / "<1" (Q02), dashes and unparsed text
  (Q04), the hand-written rows 25 and *bottom* (Q05), and absences (Q03).

```{r}
    isTRUE(all.equal(q1("SELECT SUM(measurement_value) FROM obs"), sum(src_obs$value))),

        WHERE s.sample_key IS NULL") == 0,

  "every obs.taxon_key must resolve in taxon" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN taxon t USING (taxon_key)
        WHERE t.taxon_key IS NULL") == 0,
  "every obs.measurement_type must resolve in measurement_type" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN measurement_type t USING (measurement_type)
        WHERE t.measurement_type IS NULL") == 0,

    q1("SELECT COUNT(*) FROM obs WHERE measurement_value < 0 OR measurement_value > 100") == 0,
  "unit_unclear must mean exactly the whole numbers 1-5" =
    q1("SELECT COUNT(*) FROM obs WHERE measurement_qual LIKE 'unit_unclear%'") ==
      sum(src_obs$unit == "unit_unclear"),

    core_n$sample_measurement == nrow(src_vol),
  "no cruise_key is invented (Q08)" =
    q1("SELECT COUNT(cruise_key) FROM sample") == 0)

         COUNT(*) AS n_obs,
         SUM(CASE WHEN o.measurement_qual LIKE 'unit_unclear%' THEN 1 ELSE 0 END) AS n_unit_unclear,
         ROUND(AVG(o.measurement_value), 1) AS mean_value
  FROM obs o LEFT JOIN taxon t USING (taxon_key)
  GROUP BY 1, 2 ORDER BY n_obs DESC") |>
  datatable(caption = "obs by resolved taxon", rownames = FALSE)
```

## Validate

```{r}
#| label: validate

results <- validate_for_release(con, checks = "all", strict = FALSE)
cat("Validation:", ifelse(results$passed, "PASSED", "FAILED"), "\n")
if (length(results$errors) > 0)
  cat("Errors:\n", paste("-", results$errors, collapse = "\n"), "\n")
if (length(results$warnings) > 0)
  cat("Warnings:\n", paste("-", results$warnings, collapse = "\n"), "\n")

# validate_for_release() treats every *_id / *_key column as required, a
# heuristic rather than this dataset's contract. Every expected NULL is declared
# with its count and reason; anything undeclared, or a count that moves, fails.
# Counts from the first render, 2026-10-12. All six stations fall in one grid
# cell (st50-ln66.7), so grid_key is not on this list.
nullable <- tribble(
  ~table,   ~column,             ~n,    ~reason,
  "sample", "cruise_key",        1702L, "Hopkins weekly day trips, not CalCOFI ship cruises (Q08)",
  "sample", "site_key",          1702L, "the six Hopkins stations are not on the CalCOFI line/station pattern (Q08)",
  "sample", "parent_sample_key", 1702L, "each tow is a root sample; no parent event in this dataset",
  "obs",    "cruise_key",        2462L, "inherits the sample's NULL cruise_key (Q08)",
  # 98 taxa = 23 crosswalk taxa + their WoRMS lineage ancestors
  "taxon",  "itis_id",           14L,   "WoRMS links no ITIS TSN for these lineage nodes",
  "taxon",  "gbif_id",           98L,   "nothing asks GBIF; no GBIF crosswalk in the xref",
  "taxon",  "ncbi_id",           98L,   "never populated by any dataset",
  "taxon",  "inat_id",           98L,   "never populated by any dataset",
  "taxon",  "parent_taxon_key",  1L,    "the lineage root (Biota) has no parent")

nulls <- results$checks |>
  filter(check == "nulls", status != "PASS") |>
  mutate(column = str_match(message, "column '([^']+)'")[, 2],
         n      = as.integer(str_match(message, "has (\\d+) NULL")[, 2])) |>
  select(table, column, n)

reconciled  <- full_join(nulls, select(nullable, table, column, n_expected = n),
                         by = c("table", "column"))
unexplained <- filter(reconciled, is.na(n_expected))
moved       <- filter(reconciled, !is.na(n_expected), !is.na(n), n != n_expected)
resolved    <- filter(reconciled, !is.na(n_expected), is.na(n))
if (nrow(unexplained)) print(unexplained)
if (nrow(moved)) print(moved)
stopifnot(
  "a NULL appeared in a column with no declared reason: investigate, don't just add it" =
    nrow(unexplained) == 0,
  "a declared NULL count changed: the data moved, so re-derive the reason" =
    nrow(moved) == 0)
if (nrow(resolved))
  cat(glue("{nrow(resolved)} declared nullable case(s) no longer occur, prune them: ",
           "{paste(resolved$table, resolved$column, sep = '.', collapse = ', ')}"), "\n")
cat("validate: every NULL is declared\n")
```
