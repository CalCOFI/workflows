1 Overview

Source: EDI package knb-lter-cce.249.3 (Marine Life Research Group, Michael Mullin), entity SizeFractionatedChl (table_249.csv): 422 rows, 8 columns, 12 quarterly CalCOFI cruises, 1994-01 to 1996-10, completed. Fetched by libs/download_chl_size_fractionated.R, revision and md5 pinned.

  • Grain: one row per station occupation (studyName x Station ID), each a value integrated over 0-100 m from the bottle cast: total chlorophyll a (ten GF/F samples, integrated algebraically) and chlorophyll a >= 8 um (one physically combined sample through an 8 um membrane filter).
  • No time, position or depth in the source. Each row carries only its cruise and station, and the station’s line is rounded to a whole number for lines 76.7, 81.8, 83.3 and 86.7 (077.0 060.0 is station 76.7 60.0); station_crosswalk.csv maps all 48 source stations to official ones (Q03; 087.0 039.5 is station 86.7 40.0, the only station that line has between 35 and 45). Time and position come from the matching calcofi_bottle cast: same cruise_key and site_key (match_by_site_datetime()), and the cast’s own cruise_key must equal the one minted from the source’s Cruise designation and ship code (asserted).
  • Published: chl_a_int_100m and chl_a_gt8um_int_100m (mg/m2), as obs on a cast sample spanning 0-100 m.
  • Not published (kept in the archived source):
    • Chl a < 8um: total minus >= 8 um, per the EML (asserted to the rounding).
    • Nitracline Depth: a property of the cast’s nutrient profile, which calcofi_bottle already holds.
    • Total Zooplankton Displacement Volume: from a net tow, not the bottle cast; whether it is the same measurement swfsc_ichthyo already publishes is Q02.

5 Time, Position and Cruise from the Bottle Cast

The source names the cruise and station only. match_by_site_datetime() finds the calcofi_bottle cast with the same cruise_key and site_key (key cruise_site), taking the one nearest the 15th of the designated month if a station was occupied twice. The cast gives the row its time, position and cruise_key.

## Overview

**Source**: EDI package `knb-lter-cce.249.3` (Marine Life Research Group, Michael
Mullin), entity *SizeFractionatedChl* (`table_249.csv`): 422 rows, 8 columns, 12
quarterly CalCOFI cruises, 1994-01 to 1996-10, completed. Fetched by
`libs/download_chl_size_fractionated.R`, revision and md5 pinned.

- **Grain**: one row per station occupation (`studyName` x `Station ID`), each a
  value integrated over 0-100 m from the bottle cast: total chlorophyll a (ten
  GF/F samples, integrated algebraically) and chlorophyll a >= 8 um (one
  physically combined sample through an 8 um membrane filter).
- **No time, position or depth in the source.** Each row carries only its
  cruise and station, and the station's line is rounded to a whole number for
  lines 76.7, 81.8, 83.3 and 86.7 (`077.0 060.0` is station 76.7 60.0);
  `station_crosswalk.csv` maps all 48 source stations to official ones (Q03;
  `087.0 039.5` is station 86.7 40.0, the only station that line has between 35 and 45).
  Time and position come from the matching `calcofi_bottle` cast: same
  `cruise_key` and `site_key`
  (`match_by_site_datetime()`), and the cast's own `cruise_key` must equal the
  one minted from the source's `Cruise` designation and ship code (asserted).
- **Published**: `chl_a_int_100m` and `chl_a_gt8um_int_100m` (mg/m2), as `obs` on
  a `cast` sample spanning 0-100 m.
- **Not published** (kept in the archived source):
  - `Chl a < 8um`: total minus >= 8 um, per the EML (asserted to the rounding).
  - `Nitracline Depth`: a property of the cast's nutrient profile, which
    `calcofi_bottle` already holds.
  - `Total Zooplankton Displacement Volume`: from a net tow, not the bottle
    cast; whether it is the same measurement `swfsc_ichthyo` already publishes
    is Q02.

```{mermaid}
graph LR
  A[EDI knb-lter-cce.249.3<br/>422 rows] --> B[chl_size_station<br/>cruise x station]
  B -.cruise_key + site_key.-> C[(calcofi_bottle cast<br/>time, position)]
  B --> D[chl_size_measurement<br/>long: chl_a_int_100m, chl_a_gt8um_int_100m]
```

## Clean, Type-Cast

```{r}
#| label: clean-cast
num <- function(x) suppressWarnings(as.numeric(if_else(x == "", NA_character_, x)))

# the source writes lines 76.7 / 81.8 / 83.3 / 86.7 rounded to whole numbers
# (077.0, 082.0, 083.0, 087.0); metadata/.../station_crosswalk.csv maps each
# source Station ID to the official station (Q03)
d_xwalk <- read_csv(file.path(dir_meta, "station_crosswalk.csv"), col_types = cols(.default = "c"))
stopifnot("every source Station ID is in station_crosswalk.csv" =
            all(d_raw$site_key %in% d_xwalk$station_id_src))

d_station <- d_raw |>
  rename(station_id_src = site_key) |>
  left_join(d_xwalk |> select(station_id_src, site_key), by = "station_id_src") |>
  mutate(
    across(c(chl_a_total, chl_a_gt8um, chl_a_lt8um, zooplankton_dv_ml_1000m3,
             nitracline_depth_m), num),
    site_key   = normalize_site_key(site_key),
    ship_code  = str_extract(study_name, "[0-9A-Z]+$"),
    # the cruise key the source designates: YYYY-MM (its Cruise) + the ship's NODC code
    cruise_key_src = paste0(substr(cruise_ym, 1, 4), "-", substr(cruise_ym, 5, 6), "-", ship_code),
    sample_key_id  = paste(study_name, str_replace(site_key, " ", "_"), sep = "-")) |>
  arrange(study_name, site_key) |>
  mutate(station_id = row_number())

stopifnot(
  "every row has a station, a YYYYMM Cruise and both published values" =
    !anyNA(d_station$site_key) && !anyNA(d_station$chl_a_total) && !anyNA(d_station$chl_a_gt8um) &&
    all(str_detect(d_station$cruise_ym, "^\\d{4}(0[1-9]|1[0-2])$")),
  "one row per cruise x station" = !anyDuplicated(d_station$sample_key_id),
  "< 8 um = total - >= 8 um (not published, derivable)" =
    max(abs(d_station$chl_a_total - d_station$chl_a_gt8um - d_station$chl_a_lt8um)) < 1e-6,
  ">= 8 um never exceeds total (the EML caps it at 100%)" =
    all(d_station$chl_a_gt8um <= d_station$chl_a_total))
cat(glue("{nrow(d_station)} station occupations on {n_distinct(d_station$study_name)} cruises"), "\n")
dbWriteTable(con, "chl_size_station", d_station, overwrite = TRUE)
```

## Time, Position and Cruise from the Bottle Cast

The source names the cruise and station only. `match_by_site_datetime()` finds
the `calcofi_bottle` cast with the same `cruise_key` and `site_key` (key
`cruise_site`), taking the one nearest the 15th of the designated month if a
station was occupied twice. The cast gives the row its time, position and
`cruise_key`.

```{r}
#| label: match-cast
dbExecute(con, glue("
  CREATE OR REPLACE TABLE bottle_cast AS
  SELECT sample_key AS cast_sample_key, cruise_key, site_key, datetime, latitude, longitude,
         cruise_key || ' ' || site_key AS cruise_site
  FROM read_parquet('{shard_path('calcofi_bottle', 'sample')}')
  WHERE sample_type = 'cast' AND site_key IS NOT NULL AND cruise_key IS NOT NULL
    AND datetime IS NOT NULL
    AND cruise_key IN (SELECT DISTINCT cruise_key_src FROM chl_size_station)"))

dbExecute(con, "ALTER TABLE chl_size_station ADD COLUMN IF NOT EXISTS cruise_site VARCHAR")
dbExecute(con, "ALTER TABLE chl_size_station ADD COLUMN IF NOT EXISTS nominal_date TIMESTAMP")
dbExecute(con, "
  UPDATE chl_size_station SET
    cruise_site  = cruise_key_src || ' ' || site_key,
    nominal_date = make_timestamp(CAST(substr(cruise_ym, 1, 4) AS BIGINT),
                                  CAST(substr(cruise_ym, 5, 2) AS BIGINT), 15, 0, 0, 0)")

n_multi <- dbGetQuery(con, "
  SELECT COUNT(*) FROM (SELECT cruise_site FROM bottle_cast
    WHERE cruise_site IN (SELECT cruise_site FROM chl_size_station)
    GROUP BY 1 HAVING COUNT(*) > 1)")[[1]]
cat(glue("station occupations with more than one bottle cast on the cruise: {n_multi}"), "\n")

m_cast <- match_by_site_datetime(
  con, "chl_size_station", "bottle_cast",
  fk_col = "cast_sample_key", ref_pk = "cast_sample_key",
  key_col = "cruise_site", datetime_col = "nominal_date",
  ref_datetime_col = "datetime", window_days = 45)

dbExecute(con, "ALTER TABLE chl_size_station ADD COLUMN IF NOT EXISTS cruise_key VARCHAR")
dbExecute(con, "ALTER TABLE chl_size_station ADD COLUMN IF NOT EXISTS datetime_start_utc TIMESTAMP")
dbExecute(con, "ALTER TABLE chl_size_station ADD COLUMN IF NOT EXISTS latitude DOUBLE")
dbExecute(con, "ALTER TABLE chl_size_station ADD COLUMN IF NOT EXISTS longitude DOUBLE")
dbExecute(con, "
  UPDATE chl_size_station s SET cruise_key = c.cruise_key, datetime_start_utc = c.datetime,
         latitude = c.latitude, longitude = c.longitude
  FROM bottle_cast c WHERE c.cast_sample_key = s.cast_sample_key")

d_unmatched <- dbGetQuery(con, "
  SELECT study_name, cruise_key_src, site_key FROM chl_size_station
  WHERE cast_sample_key IS NULL ORDER BY 1, 3")
d_unmatched |> datatable(caption = "Station occupations with no calcofi_bottle cast (held out, Q01)", rownames = FALSE)
cat(glue("bottle cast matched: {m_cast$matched}/{m_cast$total}"), "\n")
stopifnot(
  "a matched cast's cruise_key is the one the source designates" =
    dbGetQuery(con, "SELECT COUNT(*) FROM chl_size_station
                     WHERE cast_sample_key IS NOT NULL AND cruise_key <> cruise_key_src")[[1]] == 0,
  # ratchet: every occupation found its cast once 087.0 039.5 was mapped to 86.7 40.0
  # (Q03; 411 of 422 before)
  "every station occupation finds its cast" = m_cast$matched == m_cast$total)

dbExecute(con, "CREATE OR REPLACE TABLE chl_size_pub AS
                SELECT * FROM chl_size_station WHERE cast_sample_key IS NOT NULL")
```

```{r}
#| label: pivot-long
d_meas <- dbGetQuery(con, "SELECT station_id, chl_a_total, chl_a_gt8um FROM chl_size_pub") |>
```

```{r}
#| label: emit_core
append_sample(con, sample_arm_self(
  ds_key, "chl_size_pub", "sample_key_id", "cast",
  dt_col = "datetime_start_utc", site_expr = "site_key",
  depth_min = "0::DOUBLE", depth_max = "100::DOUBLE"))

append_obs(con, glue("
  SELECT 'env', '{ds_key}', {ns_key(ds_key, 'cast', 's.sample_key_id')},
         s.grid_key, s.cruise_key, s.latitude, s.longitude,
         CAST(s.datetime_start_utc AS TIMESTAMP), 0::DOUBLE, 100::DOUBLE,
         NULL::VARCHAR, NULL::VARCHAR, m.measurement_type, m.measurement_value,
         NULL::VARCHAR, NULL::DOUBLE
  FROM chl_size_measurement m JOIN chl_size_pub s USING (station_id)"))

q1 <- function(sql) dbGetQuery(con, sql)[[1]]
core <- list(sample = q1("SELECT COUNT(*) FROM sample"), obs = q1("SELECT COUNT(*) FROM obs"))
cat(glue("core projection -- sample={core$sample} obs={core$obs}"), "\n")
stopifnot(
  "one sample per published station occupation" = core$sample == q1("SELECT COUNT(*) FROM chl_size_pub"),
  "two obs per sample" = core$obs == 2 * core$sample,
  "obs value total equals the source" =
    isTRUE(all.equal(q1("SELECT SUM(measurement_value) FROM obs"),
                     q1("SELECT SUM(measurement_value) FROM chl_size_measurement"))),
  "sample_key is unique" = q1("SELECT COUNT(*) - COUNT(DISTINCT sample_key) FROM sample") == 0,
  "every obs.sample_key resolves in sample" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN sample s USING (sample_key) WHERE s.sample_key IS NULL") == 0)
```
