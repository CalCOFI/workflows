1 Overview

Source: GBIF/OBIS Darwin Core Archive, DOI 10.15468/n52j6r (“CalCOFI October 2022 Vertebrate eDNA”). Linked to Patin et al. 2026 (Methods in Ecology and Evolution, https://doi.org/10.1111/2041-210x.70370). 201 occurrence records from 47 water-filter samples collected 2022-10-13 to 2022-10-18 at CalCOFI/GEMCAP stations, each filter run through up to two molecular assays: mitochondrial D-loop (cetacean detections – Delphinus, Megaptera novaeangliae) and 12S rRNA “MiFish” (fish detections). Source datasetID is CalCOFI_Intercal – an intercalibration exercise, published as a CalCOFI program product (provider calcofi, not sio: see provider.csv – this dataset is branded and identified as CalCOFI’s own, unlike e.g. sio_mesopelagic-fish, which is an SIO lab collection CalCOFI merely sampled for).

Not a wide CSV. This ingest reads the DwC-A’s three tables directly (occurrence.txt, dnaderiveddata.txt, extendedmeasurementorfact.txt, tab-delimited) instead of read_csv_files(), the same way ingest_calcofi_ctd-cast.qmd bypasses it for its own non-CSV source. The source zip (dwca-calcofi_*.zip, GBIF’s DwC-A download) lives at dir_data/{provider}/{dataset}/ – data-public/calcofi/2022-edna/ – the same convention as every other dataset’s folder (bottle/, ctd-cast/, dic/, mets/), not a special genomics/ location. A second zip in that folder (GBIF’s raw occurrence-download export) is not used here – the DwC-A is the complete, canonical source; the other is a redundant representation kept for reference.

Sample grain is parentEventID, not eventID. Every eventID under a given parentEventID shares identical decimalLatitude/decimalLongitude/ minimumDepthInMeters/eventDate (checked against all 201 rows: 0/47 groups disagree) – the eventID split is the assay dimension (D-loop vs MiFish), not a distinct physical event. Treating eventID as the sample grain would duplicate every filter’s coordinates once per assay it ran (up to 2x) and double-count “samples per station” in any consumer query. This mirrors calcofi_bottle, where one physical bottle (not each bottle_measurement row) is the sample.

4 Check Data Integrity

No read_csv_files() result to hand check_data_integrity(), so integrity is checked directly against the shape this ingest actually depends on: every occurrenceID unique, every occurrence joins 1:1 to dnaderiveddata (the assay source), every parentEventID group internally agrees on position/time/depth (the sample-grain decision above), and no occurrenceStatus other than present (no absence records to filter).

7 Assay (D-loop vs MiFish) Lookup

The molecular assay is a property of the detection, not the sample (one filter carries detections from both assays) – it comes from dnaderiveddata.target_gene, joined by occurrenceID. Carried as an obs_attribute row (measurement_type = ‘assay’, bin_label = the assay name), matching how ingest_farallon_bird-mammal.qmd records behavior – Q02, RESOLVED against the real obs_attribute schema.

Code 
dbWriteTable(con, "edna_dna", as.data.frame(d_dna), overwrite = TRUE)

d_assay <- dbGetQuery(con, "
  SELECT o.occurrenceID, o.parentEventID, o.eventID, o.scientificNameID,
         o.organismQuantity,
         CASE d.target_gene
           WHEN 'D-loop' THEN 'D-loop'
           WHEN '12S rRNA (SSU mitochondria)' THEN '12S (MiFish)'
           ELSE d.target_gene
         END AS assay
  FROM edna_occurrence o JOIN edna_dna d USING (occurrenceID)")
dbWriteTable(con, "edna_assay", d_assay, overwrite = TRUE)

d_assay |> count(assay) |>
  datatable(caption = "Detections by assay", rownames = FALSE)

9 Water Chemistry + Genomics QC (sample_measurement)

extendedmeasurementorfact.txt is 12,632 rows, but only 7 fields are real per-sample measurements (identical across every occurrence sharing a parentEventID, confirmed for all 47 groups) plus 4 genomics QC values; the other ~50 distinct measurementType values are FAIRe-checklist protocol text (kit names, SOP links, extraction dates) with no place in a value/unit table. Six of the seven measurements reuse existing canonical measurement_type rows by exact unit match (ammonia, nitrate, nitrite, phosphate, silicate, chl_fluor, all confirmed against the live v2026.07.30 release schema); dissolved oxygen is reported in mg/L, which no existing oxygen type uses, so it gets a new oxygen_mg_l type rather than a guessed conversion (Q03).

Code 
dbWriteTable(con, "edna_emof", as.data.frame(d_emof), overwrite = TRUE)

emof_type_map <- tribble(
  ~source_type,                              ~measurement_type,
  "Concentration of ammonia in the sample",   "ammonia",
  "Concentration of nitrate in the sample",   "nitrate",
  "Concentration of nitrite in the sample",   "nitrite",
  "Concentration of phosphate in the sample", "phosphate",
  "Concentration of silicate in the sample",  "silicate",
  "Chlorophyll fluorescence",                 "chl_fluor",
  "Concentration of dissolved oxygen",        "oxygen_mg_l",
  "Concentration of total DNA after extraction", "dna_concentration",
  "The total number of raw sequence reads for each sample.", "reads_raw_total",
  "The number of filtered sequence reads for each sample, that made it through bioinformatic filtering and used for final/subsequent analyses.", "reads_filtered_total",
  "Total number of OTUs or ASVs assigned to taxa based on the study-specific thresholds for each sample", "otu_richness")

dbWriteTable(con, "emof_type_map", emof_type_map, overwrite = TRUE)

# dedupe to one value per (parentEventID, measurement_type): every eventID
# child of a parentEventID carries an identical context value (checked above
# for ammonia; same join logic covers all seven), so MIN() here is a
# tie-break over identical values, not an aggregation.
d_context <- dbGetQuery(con, "
  SELECT o.parentEventID, m.measurement_type,
         MIN(TRY_CAST(e.measurementValue AS DOUBLE)) AS measurement_value
  FROM edna_emof e
  JOIN edna_occurrence o USING (occurrenceID)
  JOIN emof_type_map m ON m.source_type = e.measurementType
  GROUP BY o.parentEventID, m.measurement_type")
dbWriteTable(con, "edna_context", d_context, overwrite = TRUE)

n_dropped_types <- dbGetQuery(con, "
  SELECT COUNT(DISTINCT measurementType) FROM edna_emof
  WHERE measurementType NOT IN (SELECT source_type FROM emof_type_map)")[[1]]
cat(glue(
  "sample_measurement staged: {nrow(d_context)} rows across {nrow(emof_type_map)} types, ",
  "{n_parent <- n_distinct(d_context$parentEventID)} samples; ",
  "{n_dropped_types} protocol-text measurementTypes excluded (not measurements)"), "\n")

12 Emit Core Tables

Projection lives here, in the notebook, per the no-switch(dataset_key, ...) rule – no calcofi4db change needed for this dataset.

Code 
# 1. sample -- one row per physical water filter (parentEventID grain)
append_sample(con, glue("
  SELECT {ns_key(ds_key, 'sample', 'parent_event_id')} AS sample_key,
         'filter' AS sample_type, NULL::VARCHAR AS parent_sample_key,
         {ns_key(ds_key, 'sample', 'parent_event_id')} AS root_sample_key,
         '{ds_key}' AS dataset_key, grid_key, NULL::VARCHAR AS site_key, cruise_key,
         NULL::INTEGER AS order_occ,
         latitude, longitude, datetime_start_utc AS datetime,
         depth_min_m, depth_max_m, NULL::VARCHAR AS tow_type
  FROM edna_sample"))

# 2. obs -- species detections, headline measurement = sequence_reads
# Positional order confirmed against calcofi_bottle/calcofi_dic/cce-lter_euphausiids
# (identical arg order in all three): realm, dataset_key, sample_key, grid_key,
# cruise_key, latitude, longitude, datetime, depth_min_m, depth_max_m, taxon_key,
# life_stage, measurement_type, measurement_value, measurement_qual,
# measurement_prec. life_stage is NULL for eDNA reads -- there is no life-stage
# field on a water-filter detection (occurrence.txt has no lifeStage column
# either); the source's identificationRemarks was a guess with no home in this
# schema and has been dropped.
append_obs(con, glue("
  SELECT 'bio', '{ds_key}', {ns_key(ds_key, 'sample', 'a.parentEventID')},
         s.grid_key, s.cruise_key, s.latitude, s.longitude, s.datetime_start_utc,
         s.depth_min_m, s.depth_max_m,
         dt.taxon_key, NULL::VARCHAR,
         'sequence_reads', CAST(a.organismQuantity AS DOUBLE),
         NULL::VARCHAR, NULL::DOUBLE
  FROM edna_assay a
  JOIN edna_sample s ON s.parent_event_id = a.parentEventID
  LEFT JOIN dataset_taxon dt ON dt.dataset_key = '{ds_key}'
                            AND dt.ds_taxa_code = a.scientificNameID"))

# 3. obs_attribute -- assay dimension per detection. Positional order confirmed
# against swfsc_ichthyo/calcofi_phyllosoma/cdfw_dungeness-crab/farallon_bird-mammal:
# dataset_key, sample_key, taxon_key, life_stage, measurement_type, bin_value,
# bin_label, count, measurement_qual. The assay label ('D-loop'/'12S (MiFish)')
# is categorical text, so it belongs in bin_label (position 7) -- confirmed
# against the real obs_attribute schema at calcofi.io/db-schema. Resolves Q02.
append_obs_attribute(con, glue("
  SELECT '{ds_key}', {ns_key(ds_key, 'sample', 'a.parentEventID')},
         dt.taxon_key, NULL::VARCHAR, 'assay',
         NULL::DOUBLE, a.assay, NULL::INTEGER, NULL::VARCHAR
  FROM edna_assay a
  LEFT JOIN dataset_taxon dt ON dt.dataset_key = '{ds_key}'
                            AND dt.ds_taxa_code = a.scientificNameID"))

# 4. sample_measurement -- co-collected water chemistry + genomics QC
append_sample_measurement(con, glue("
  SELECT {ns_key(ds_key, 'sample', 'parentEventID')}, '{ds_key}',

## Overview

**Source**: GBIF/OBIS Darwin Core Archive, DOI
[10.15468/n52j6r](https://www.gbif.org/dataset/10524092-539d-4ea4-8539-2e91ad8581a9)
("CalCOFI October 2022 Vertebrate eDNA"). Linked to Patin et al. 2026
(*Methods in Ecology and Evolution*, https://doi.org/10.1111/2041-210x.70370).
201 occurrence records from 47 water-filter samples collected 2022-10-13 to
2022-10-18 at CalCOFI/GEMCAP stations, each filter run through up to two
molecular assays: mitochondrial D-loop (cetacean detections -- *Delphinus*,
*Megaptera novaeangliae*) and 12S rRNA "MiFish" (fish detections). Source
`datasetID` is `CalCOFI_Intercal` -- an intercalibration exercise, published
as a CalCOFI program product (provider `calcofi`, not `sio`: see
`provider.csv` -- this dataset is branded and identified as CalCOFI's own,
unlike e.g. `sio_mesopelagic-fish`, which is an SIO lab collection CalCOFI
merely sampled for).

**Not a wide CSV.** This ingest reads the DwC-A's three tables directly
(`occurrence.txt`, `dnaderiveddata.txt`, `extendedmeasurementorfact.txt`,
tab-delimited) instead of `read_csv_files()`, the same way
`ingest_calcofi_ctd-cast.qmd` bypasses it for its own non-CSV source. The
source zip (`dwca-calcofi_*.zip`, GBIF's DwC-A download) lives at
`dir_data/{provider}/{dataset}/` -- `data-public/calcofi/2022-edna/` -- the
same convention as every other dataset's folder (`bottle/`, `ctd-cast/`,
`dic/`, `mets/`), not a special `genomics/` location. A second zip in that
folder (GBIF's raw occurrence-download export) is not used here -- the DwC-A
is the complete, canonical source; the other is a redundant representation
kept for reference.

**Sample grain is `parentEventID`, not `eventID`.** Every `eventID` under a
given `parentEventID` shares identical `decimalLatitude`/`decimalLongitude`/
`minimumDepthInMeters`/`eventDate` (checked against all 201 rows: 0/47 groups
disagree) -- the `eventID` split is the assay dimension (D-loop vs MiFish), not
a distinct physical event. Treating `eventID` as the sample grain would
duplicate every filter's coordinates once per assay it ran (up to 2x) and
double-count "samples per station" in any consumer query. This mirrors
`calcofi_bottle`, where one physical bottle (not each `bottle_measurement`
row) is the sample.

## Water Chemistry + Genomics QC (sample_measurement)

`extendedmeasurementorfact.txt` is 12,632 rows, but only 7 fields are real

```{r}
  "Concentration of ammonia in the sample",   "ammonia",
  "Concentration of nitrate in the sample",   "nitrate",
  "Concentration of nitrite in the sample",   "nitrite",
  "Concentration of phosphate in the sample", "phosphate",
  "Concentration of silicate in the sample",  "silicate",
  "Chlorophyll fluorescence",                 "chl_fluor",
  "Concentration of dissolved oxygen",        "oxygen_mg_l",
  "Concentration of total DNA after extraction", "dna_concentration",
  "The total number of raw sequence reads for each sample.", "reads_raw_total",
  "The number of filtered sequence reads for each sample, that made it through bioinformatic filtering and used for final/subsequent analyses.", "reads_filtered_total",
  "Total number of OTUs or ASVs assigned to taxa based on the study-specific thresholds for each sample", "otu_richness")

dbWriteTable(con, "emof_type_map", emof_type_map, overwrite = TRUE)

# dedupe to one value per (parentEventID, measurement_type): every eventID
# child of a parentEventID carries an identical context value (checked above
# for ammonia; same join logic covers all seven), so MIN() here is a
# tie-break over identical values, not an aggregation.
d_context <- dbGetQuery(con, "
  SELECT o.parentEventID, m.measurement_type,
         MIN(TRY_CAST(e.measurementValue AS DOUBLE)) AS measurement_value
  FROM edna_emof e
  JOIN edna_occurrence o USING (occurrenceID)
  JOIN emof_type_map m ON m.source_type = e.measurementType
  GROUP BY o.parentEventID, m.measurement_type")
dbWriteTable(con, "edna_context", d_context, overwrite = TRUE)

n_dropped_types <- dbGetQuery(con, "
  SELECT COUNT(DISTINCT measurementType) FROM edna_emof
  WHERE measurementType NOT IN (SELECT source_type FROM emof_type_map)")[[1]]
cat(glue(
  "sample_measurement staged: {nrow(d_context)} rows across {nrow(emof_type_map)} types, ",
  "{n_parent <- n_distinct(d_context$parentEventID)} samples; ",
  "{n_dropped_types} protocol-text measurementTypes excluded (not measurements)"), "\n")
```

## Emit Core Tables

Projection lives here, in the notebook, per the no-`switch(dataset_key, ...)`
rule -- no `calcofi4db` change needed for this dataset.

```{r}
#| label: emit-core

# 1. sample -- one row per physical water filter (parentEventID grain)
append_sample(con, glue("
  SELECT {ns_key(ds_key, 'sample', 'parent_event_id')} AS sample_key,
         'filter' AS sample_type, NULL::VARCHAR AS parent_sample_key,
         {ns_key(ds_key, 'sample', 'parent_event_id')} AS root_sample_key,
         '{ds_key}' AS dataset_key, grid_key, NULL::VARCHAR AS site_key, cruise_key,
         NULL::INTEGER AS order_occ,
         latitude, longitude, datetime_start_utc AS datetime,
         depth_min_m, depth_max_m, NULL::VARCHAR AS tow_type
  FROM edna_sample"))

# 2. obs -- species detections, headline measurement = sequence_reads
# Positional order confirmed against calcofi_bottle/calcofi_dic/cce-lter_euphausiids
# (identical arg order in all three): realm, dataset_key, sample_key, grid_key,
# cruise_key, latitude, longitude, datetime, depth_min_m, depth_max_m, taxon_key,
# life_stage, measurement_type, measurement_value, measurement_qual,
# measurement_prec. life_stage is NULL for eDNA reads -- there is no life-stage
# field on a water-filter detection (occurrence.txt has no lifeStage column
# either); the source's identificationRemarks was a guess with no home in this
# schema and has been dropped.
append_obs(con, glue("
  SELECT 'bio', '{ds_key}', {ns_key(ds_key, 'sample', 'a.parentEventID')},
         s.grid_key, s.cruise_key, s.latitude, s.longitude, s.datetime_start_utc,
         s.depth_min_m, s.depth_max_m,
         dt.taxon_key, NULL::VARCHAR,
         'sequence_reads', CAST(a.organismQuantity AS DOUBLE),
         NULL::VARCHAR, NULL::DOUBLE
  FROM edna_assay a
  JOIN edna_sample s ON s.parent_event_id = a.parentEventID
  LEFT JOIN dataset_taxon dt ON dt.dataset_key = '{ds_key}'
                            AND dt.ds_taxa_code = a.scientificNameID"))

# 3. obs_attribute -- assay dimension per detection. Positional order confirmed
# against swfsc_ichthyo/calcofi_phyllosoma/cdfw_dungeness-crab/farallon_bird-mammal:
# dataset_key, sample_key, taxon_key, life_stage, measurement_type, bin_value,
# bin_label, count, measurement_qual. The assay label ('D-loop'/'12S (MiFish)')
# is categorical text, so it belongs in bin_label (position 7) -- confirmed
# against the real obs_attribute schema at calcofi.io/db-schema. Resolves Q02.
append_obs_attribute(con, glue("
  SELECT '{ds_key}', {ns_key(ds_key, 'sample', 'a.parentEventID')},
         dt.taxon_key, NULL::VARCHAR, 'assay',
         NULL::DOUBLE, a.assay, NULL::INTEGER, NULL::VARCHAR
  FROM edna_assay a
  LEFT JOIN dataset_taxon dt ON dt.dataset_key = '{ds_key}'
                            AND dt.ds_taxa_code = a.scientificNameID"))

# 4. sample_measurement -- co-collected water chemistry + genomics QC
append_sample_measurement(con, glue("
  SELECT {ns_key(ds_key, 'sample', 'parentEventID')}, '{ds_key}',
         measurement_type, measurement_value, NULL::VARCHAR
  FROM edna_context"))

core <- list(
  sample             = dbGetQuery(con, "SELECT COUNT(*) FROM sample WHERE dataset_key = 'calcofi_2022-edna'")[[1]],
  obs                = dbGetQuery(con, "SELECT COUNT(*) FROM obs WHERE dataset_key = 'calcofi_2022-edna'")[[1]],
  obs_attribute      = dbGetQuery(con, "SELECT COUNT(*) FROM obs_attribute WHERE dataset_key = 'calcofi_2022-edna'")[[1]],

n_unresolved_taxon <- dbGetQuery(con,
  "SELECT COUNT(*) FROM obs WHERE dataset_key = 'calcofi_2022-edna' AND taxon_key IS NULL")[[1]]
```
