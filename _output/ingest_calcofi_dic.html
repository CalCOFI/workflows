1 Overview

Source: DIC | CalCOFI.org

Dissolved Inorganic Carbon (DIC) and Total Alkalinity (TA) from CalCOFI Niskin bottle samples, archived at NCEI accession 0301029.

  • Provider: calcofi (CalCOFI program; PI: Todd Martz, Scripps)
  • File: CALCOFI_DIC_20250122.csv (~500KB, 4,391 rows)
  • Coverage: 1983–2021, 71 stations, 131 cruises
  • Measurements: DIC (umol/kg), TA (umol/kg), CTD temperature (degC), salinity (PSS-78)
  • Quality flags: WOCE convention (2=good, 3=questionable, 4=bad, 9=missing)
  • Citation: Keeling, C.D. et al. (2025). Discrete profile dissolved inorganic carbon, total alkalinity, water temperature and salinity measurements … for the CalCOFI program in the North East Pacific Ocean Coastal area from 1983-03-19 to 2021-07-20 (NCEI Accession 0301029). NOAA NCEI. https://doi.org/10.25921/3w9f-jd72

Strategy: Load source CSV, pivot ALL four measurement columns (DIC, TA, CTD temperature, salinity) into tidy long-format dic_measurement, then summarize replicates into dic_summary. The base dic_sample table retains only position/time/FK columns — no measurement values.

Published scope. A DIC value on a Niskin the bottle database also carries is published once, on that bottle. A value on a sample that matches no bottle cast is published on the sample’s own key wherever the source gives a depth (the source’s Depth is metres, -999 is its missing sentinel); these values are not linked to a bottle cast. The one unmatched sample with no depth stays a sample row with no observations. See Scope of the published values and questions calcofi_dic_01 / calcofi_dic_07.

1.2 Measurement Types

Four measurement types from this dataset — all new types, distinct from bottle/CTD equivalents because these come from a separate instrument chain with WOCE QC:

measurement_type description units source column status
dic Dissolved inorganic carbon umol/kg DIC NEW
alkalinity Total alkalinity umol/kg TA NEW
ctdtemp_its90 CTD temperature (ITS-90) degC CTDTEMP_ITS90 NEW
salinity_pss78 Practical salinity (PSS-78) PSS-78 Salinity_PSS78 NEW

These are kept separate from the calcofi_bottle temperature/salinity types because the DIC dataset values come from a different QC pipeline (WOCE flags vs calcofi.org quality codes).

8 Pivot ALL Measurements to Long Format

Pivot all four measurement columns (DIC, TA, CTD temperature, salinity) into tidy long-format dic_measurement. Each row = one measurement at one position. This follows tidy data principles — no mixing of different measured quantities on the same row.

meas_map <- list(
  list(type = "dic",             col = "dic",             flag = "dic_flag"),
  list(type = "alkalinity",      col = "alkalinity",      flag = "alkalinity_flag"),
  list(type = "ctdtemp_its90",   col = "ctdtemp_its90",   flag = "ctdtemp_its90_flag"),
  list(type = "salinity_pss78",  col = "salinity_pss78",  flag = "salinity_pss78_flag")

9 Summarize Replicate Measurements

Aggregate replicate measurements at each unique position in time and space (station + date + depth) into mean and standard deviation, following ctd_summary in ingest_calcofi_ctd-cast.qmd. Filters out NaN, -Inf, Inf values.

Code 
dbExecute(
  con,
  "CREATE OR REPLACE TABLE dic_summary AS
   SELECT
     site_key,
     datetime_start_utc,
     depth_m,
     latitude,
     longitude,
     measurement_type,
     AVG(measurement_value)    AS avg,
     CASE
       WHEN COUNT(*) = 1 THEN 0
       ELSE COALESCE(STDDEV_SAMP(measurement_value), 0)
     END                       AS stddev,
     COUNT(*)                  AS n_obs,
     MAX(cast_id)              AS cast_id,
     MAX(bottle_id)            AS bottle_id
   FROM dic_measurement
   WHERE NOT isnan(measurement_value)
     AND isfinite(measurement_value)
   GROUP BY site_key, datetime_start_utc, depth_m,
            latitude, longitude, measurement_type"
)

14 Add Spatial

Three things are derived from the source’s own ship, date and position, before the geometry column exists (a table holding a CRS-tagged geom cannot be UPDATEd):

  1. ship_key — the EXPOCODE’s NODC prefix against ship.ship_nodc, else the source’s own Ship_Name against ship.ship_name (NOAA’s and SWFSC’s NODC codes differ for six ships: EXPOCODE 33RL is SWFSC 33UD, Reuben Lasker). A ship the reference does not carry (Westwind) stays NULL.
  2. cruise_key — resolve_cruise_key(): span containment on the sample’s date first, then the event’s month, keys the reference cruise table does not hold left NULL (require_in_cruise). The EXPOCODE’s own start month is not passed as a designation: calcofi_dic_07 is open, and the EXPOCODE’s start month differs from the span-resolved cruise’s month in 545 of the 1,971 rows the span alone resolves (a cruise starting 28 Jan is designated February).
  3. grid_key — from the sample’s own position (assign_grid_key()).

16 Emit Core Tables

Project this dataset into the shared consolidated core model (design_env-bio-consolidation.md). These core tables are this ingest’s output: release_database.qmd concatenates the per-dataset shards rather than re-deriving the core, so there is exactly one projection to keep correct.

DIC observations that share a physical Niskin with calcofi_bottle point at that bottle’s sample_key, so the two datasets deduplicate onto one event rather than double-counting the bottle. Only a DIC sample on a Niskin that calcofi_bottle does not carry mints its own calcofi_dic:bottle:<md5> key — and that md5 must be spelled identically in the sample and obs arms, or obs orphans.

What is published (WS-1004X2, Ben 2026-10-04). The observations of a DIC sample that matches no bottle cast are published too, on the sample’s own calcofi_dic:bottle:<md5> key, wherever the source gives the sample a depth: the source’s own depth, the grid_key of its position, the cruise_key the reference resolves (span, then month; NULL where the reference holds none) and the station the source states. These samples have no cast foreign key: parent_sample_key is NULL and root_sample_key is the sample itself, because the source names no cast (calcofi_dic_01). The values are not linked to a bottle cast, and a consumer must not join them to one. A sample the source gives no depth stays a sample row with no observations (counted and named in the scope section below). The observations of the samples that do match a cast are exactly what they were.

## Overview

**Source**: [DIC | CalCOFI.org](https://calcofi.org/data/oceanographic-data/dic/)

Dissolved Inorganic Carbon (DIC) and Total Alkalinity (TA) from CalCOFI
Niskin bottle samples, archived at NCEI accession
[0301029](https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.nodc:0301029).

- **Provider**: `calcofi` (CalCOFI program; PI: Todd Martz, Scripps)
- **File**: `CALCOFI_DIC_20250122.csv` (~500KB, 4,391 rows)
- **Coverage**: 1983–2021, 71 stations, 131 cruises
- **Measurements**: DIC (umol/kg), TA (umol/kg), CTD temperature (degC),
  salinity (PSS-78)
- **Quality flags**: WOCE convention (2=good, 3=questionable, 4=bad, 9=missing)
- **Citation**: Keeling, C.D. et al. (2025). Discrete profile dissolved
  inorganic carbon, total alkalinity, water temperature and salinity
  measurements ... for the CalCOFI program in the North East Pacific
  Ocean Coastal area from 1983-03-19 to 2021-07-20 (NCEI Accession
  0301029). NOAA NCEI. <https://doi.org/10.25921/3w9f-jd72>

**Strategy**: Load source CSV, pivot ALL four measurement columns
(DIC, TA, CTD temperature, salinity) into tidy long-format
`dic_measurement`, then summarize replicates into
`dic_summary`. The base `dic_sample` table retains only
position/time/FK columns — no measurement values.

**Published scope.** A DIC value on a Niskin the bottle database also carries is published
once, on that bottle. A value on a sample that matches **no** bottle cast is published on
the sample's own key wherever the source gives a depth (the source's `Depth` is metres,
`-999` is its missing sentinel); these values are **not linked to a bottle cast**. The one
unmatched sample with no depth stays a `sample` row with no observations. See
[Scope of the published values](#scope-of-the-published-values) and questions
`calcofi_dic_01` / `calcofi_dic_07`.

## Summarize Replicate Measurements

Aggregate replicate measurements at each unique position in time
and space (station + date + depth) into mean and standard deviation,
following `ctd_summary` in `ingest_calcofi_ctd-cast.qmd`. Filters out
`NaN`, `-Inf`, `Inf` values.

```{r}
#| label: dic-measurement-summary

dbExecute(
  con,
  "CREATE OR REPLACE TABLE dic_summary AS
   SELECT
     site_key,
     datetime_start_utc,
     depth_m,
     latitude,
     longitude,
     measurement_type,
     AVG(measurement_value)    AS avg,
     CASE
       WHEN COUNT(*) = 1 THEN 0
       ELSE COALESCE(STDDEV_SAMP(measurement_value), 0)
     END                       AS stddev,
     COUNT(*)                  AS n_obs,
     MAX(cast_id)              AS cast_id,
     MAX(bottle_id)            AS bottle_id
   FROM dic_measurement
   WHERE NOT isnan(measurement_value)
     AND isfinite(measurement_value)
   GROUP BY site_key, datetime_start_utc, depth_m,
            latitude, longitude, measurement_type"
)

n_summ <- dbGetQuery(con, "SELECT COUNT(*) FROM dic_summary")[[1]]
cat(glue(
  "dic_summary: {format(n_summ, big.mark = ',')} rows ",
  "(from {format(n_meas, big.mark = ',')} measurements)"), "\n")

dbGetQuery(
  con,
  "SELECT measurement_type,
          COUNT(*) AS n_positions,
          SUM(n_obs) AS n_raw_obs,
          ROUND(AVG(n_obs), 1) AS avg_replicates,
          SUM(CASE WHEN n_obs > 1 THEN 1 ELSE 0 END) AS n_with_replicates,
          ROUND(AVG(stddev), 3) AS avg_stddev
   FROM dic_summary
   GROUP BY measurement_type
   ORDER BY measurement_type"
) |> datatable(caption = "Replicate statistics by type")
```

## Add Spatial

Three things are derived from the source's own ship, date and position, **before** the
geometry column exists (a table holding a CRS-tagged `geom` cannot be `UPDATE`d):

1. **`ship_key`** — the EXPOCODE's NODC prefix against `ship.ship_nodc`, else the source's
   own `Ship_Name` against `ship.ship_name` (NOAA's and SWFSC's NODC codes differ for six
   ships: EXPOCODE `33RL` is SWFSC `33UD`, Reuben Lasker). A ship the reference does not
   carry (Westwind) stays NULL.
2. **`cruise_key`** — `resolve_cruise_key()`: span containment on the sample's date first, then
   the event's month, keys the reference `cruise` table does not hold left NULL
   (`require_in_cruise`). The EXPOCODE's own start month is **not** passed as a designation:
   `calcofi_dic_07` is open, and the EXPOCODE's start month differs from the span-resolved
   cruise's month in 545 of the 1,971 rows the span alone resolves (a cruise starting
   28 Jan is designated February).
3. **`grid_key`** — from the sample's own position (`assign_grid_key()`).

## Emit Core Tables

Project this dataset into the shared consolidated core model
(`design_env-bio-consolidation.md`). These core tables **are** this ingest's
output: `release_database.qmd` concatenates the per-dataset shards rather than
re-deriving the core, so there is exactly one projection to keep correct.

DIC observations that share a physical Niskin with `calcofi_bottle` point at that
bottle's `sample_key`, so the two datasets deduplicate onto one event rather than
double-counting the bottle. Only a DIC sample on a Niskin that `calcofi_bottle`
does **not** carry mints its own `calcofi_dic:bottle:<md5>` key — and that md5
must be spelled identically in the `sample` and `obs` arms, or `obs` orphans.

**What is published (WS-1004X2, Ben 2026-10-04).** The observations of a DIC sample that
matches no bottle cast are published too, on the sample's own `calcofi_dic:bottle:<md5>`
key, **wherever the source gives the sample a depth**: the source's own depth, the
`grid_key` of its position, the `cruise_key` the reference resolves (span, then month;
NULL where the reference holds none) and the station the source states. These samples
have **no cast foreign key**: `parent_sample_key` is NULL and `root_sample_key` is the
sample itself, because the source names no cast (`calcofi_dic_01`). The values are
**not linked to a bottle cast**, and a consumer must not join them to one. A sample the
source gives no depth stays a `sample` row with no observations (counted and named in
the scope section below). The observations of the samples that do match a cast are
exactly what they were.

```{r}
#| label: emit_core

ds_key <- "calcofi_dic"

# the DIC natural key, for Niskins that calcofi_bottle does not carry. Defined
# ONCE and interpolated into both arms: the sample and obs arms must agree
# byte-for-byte or obs.sample_key resolves to nothing. Columns are the ones
# dic_sample and dic_measurement share, so the two spellings align.
dic_md5 <- function(a) glue("md5(concat_ws('|', {a}.expocode,
    CAST({a}.datetime_start_utc AS VARCHAR), CAST({a}.latitude AS VARCHAR),
    CAST({a}.longitude AS VARCHAR), CAST({a}.depth_m AS VARCHAR)))")

# This projection lives here, in the notebook that owns the dataset, not in a
# switch(dataset_key, ...) arm inside calcofi4db.
#
# sample — bottle-shaped leaf events, minting ONLY the Niskins calcofi_bottle
# does not already publish (the shared ones reuse bottle's sample_key in obs
# below). Parented to the matched cast where one was found. cruise_key: a matched
# cast's own (as published since v2026.10.01); a sample that matched no cast takes the
# one resolved from its ship + date in the Add Spatial section (NULL where the
# reference cruise table holds none).
append_sample(con, glue("
  SELECT * FROM (
    SELECT 'calcofi_dic:bottle:' || {dic_md5('d')} AS sample_key, 'bottle' AS sample_type,
           CASE WHEN c.cast_id IS NULL THEN NULL
                ELSE 'calcofi_bottle:cast:' || CAST(c.cast_id AS VARCHAR) END AS parent_sample_key,
           COALESCE(
             CASE WHEN c.cast_id IS NULL THEN NULL
                  ELSE 'calcofi_bottle:cast:' || CAST(c.cast_id AS VARCHAR) END,
             'calcofi_dic:bottle:' || {dic_md5('d')}) AS root_sample_key,
           '{ds_key}' AS dataset_key,
           COALESCE(d.grid_key, c.grid_key) AS grid_key,  -- the sample's own position; a matched cast's key only where it has none (check_grid_key_assignment())
           d.site_key,
           CASE WHEN c.cast_id IS NULL THEN d.cruise_key ELSE c.cruise_key END AS cruise_key,
           CAST(c.order_occ AS INTEGER) AS order_occ,
           d.latitude, d.longitude, CAST(d.datetime_start_utc AS TIMESTAMP) AS datetime,
           d.depth_m AS depth_min_m, d.depth_m AS depth_max_m,
           NULL::VARCHAR AS tow_type
    FROM dic_sample d LEFT JOIN casts c ON d.cast_id = c.cast_id
    WHERE d.bottle_id IS NULL OR d.bottle_id NOT IN (SELECT bottle_id FROM bottle)
  ) q QUALIFY row_number() OVER (PARTITION BY sample_key) = 1"))

# obs, arm 1 — dedup onto calcofi_bottle: a DIC row sharing a physical Niskin points at
# that bottle's sample_key; only the non-shared Niskins use the minted DIC key. Rows of
# a matched cast only: unchanged since v2026.10.01 (asserted in the scope section).
append_obs(con, glue("
  SELECT 'env', '{ds_key}',
         CASE WHEN dm.bottle_id IS NOT NULL AND dm.bottle_id IN (SELECT bottle_id FROM bottle)
              THEN 'calcofi_bottle:bottle:' || CAST(dm.bottle_id AS VARCHAR)
              ELSE 'calcofi_dic:bottle:' || {dic_md5('dm')} END,
         c.grid_key, c.cruise_key, dm.latitude, dm.longitude,
         CAST(dm.datetime_start_utc AS TIMESTAMP), dm.depth_m, dm.depth_m,
         NULL::VARCHAR, NULL::VARCHAR, dm.measurement_type, dm.measurement_value,
         dm.measurement_qual, NULL::DOUBLE
  FROM dic_measurement dm JOIN casts c USING (cast_id)"))
n_obs_cast <- dbGetQuery(con, "SELECT COUNT(*) FROM obs")[[1]]

# obs, arm 2 -- a sample that matched NO cast, wherever the source gives it a depth.
# Keyed on the sample's own minted key; grid_key / cruise_key are read back from that
# sample row, so an obs row can never disagree with its sample. There is no cast
# foreign key to fabricate: the source names none (calcofi_dic_01).
append_obs(con, glue("
  SELECT 'env', '{ds_key}', s.sample_key, s.grid_key, s.cruise_key,
         dm.latitude, dm.longitude, CAST(dm.datetime_start_utc AS TIMESTAMP),
         dm.depth_m, dm.depth_m, NULL::VARCHAR, NULL::VARCHAR,
         dm.measurement_type, dm.measurement_value, dm.measurement_qual, NULL::DOUBLE
  FROM dic_measurement dm
  JOIN sample s ON s.sample_key = 'calcofi_dic:bottle:' || {dic_md5('dm')}
  WHERE dm.cast_id IS NULL AND dm.depth_m IS NOT NULL"))

core <- list(
  sample = dbGetQuery(con, "SELECT COUNT(*) FROM sample")[[1]],
  obs    = dbGetQuery(con, "SELECT COUNT(*) FROM obs")[[1]])
cat(glue(
  "core projection — sample={core$sample %||% 0} obs={core$obs %||% 0}\n"))

n_obs <- core$obs
n_shared <- dbGetQuery(con,
  "SELECT COUNT(*) FROM obs WHERE sample_key LIKE 'calcofi_bottle:bottle:%'")[[1]]
n_dup <- dbGetQuery(con, "
  SELECT COUNT(*) FROM (SELECT sample_key FROM sample GROUP BY 1 HAVING COUNT(*) > 1)")[[1]]
stopifnot(
  "obs must be one row per DIC measurement of a matched cast, plus one per unmatched sample's measurement with a depth" =
    n_obs == dbGetQuery(con, "SELECT COUNT(*) FROM dic_measurement dm JOIN casts c USING (cast_id)")[[1]] +
             dbGetQuery(con, "SELECT COUNT(*) FROM dic_measurement
                              WHERE cast_id IS NULL AND depth_m IS NOT NULL")[[1]],
  "sample_key must be unique (the md5 dedup)" = n_dup == 0,
  # grid_key was NULL on 3,255 of 3,261 samples at v2026.10.01 (taken from the matched
  # cast alone); a sample with a position now carries its own, a cast's wins
  "every emitted DIC sample with a position must carry a grid_key" =
    dbGetQuery(con, "SELECT COUNT(*) FROM sample WHERE dataset_key = 'calcofi_dic'
                     AND grid_key IS NULL AND latitude IS NOT NULL
                     AND longitude IS NOT NULL")[[1]] == 0,
  "some DIC obs must dedup onto calcofi_bottle" = n_shared > 0,
  "every obs.sample_key must resolve in sample or in the bottle dataset" =
    dbGetQuery(con, "SELECT COUNT(*) FROM obs o LEFT JOIN sample s USING (sample_key)
                     WHERE s.sample_key IS NULL
                       AND o.sample_key NOT LIKE 'calcofi_bottle:bottle:%'")[[1]] == 0,
  # the md5 must be spelled the same in both arms: a DIC-keyed obs row whose key
  # is absent from sample means the two spellings drifted
  "every minted DIC obs key must resolve in this dataset's sample" =
    dbGetQuery(con, "SELECT COUNT(*) FROM obs o LEFT JOIN sample s USING (sample_key)
                     WHERE o.sample_key LIKE 'calcofi_dic:bottle:%'
                       AND s.sample_key IS NULL")[[1]] == 0)
cat(glue("obs: {format(n_obs, big.mark=',')} rows, {format(n_shared, big.mark=',')} ",
         "sharing a Niskin with calcofi_bottle"), "\n")
```

### Scope of the published values

Two kinds of number, kept apart on purpose (WS-1004X3). **Pins** are what this notebook
alone determines from its own source file `CALCOFI_DIC_20250122.csv`: rows, distinct samples,
the values per type, the samples with no source depth. A re-delivered file that changes them
stops the notebook. **Measured and reported** are what depends on another dataset: how many
samples match a bottle cast, and how many of those share a bottle, move whenever
`calcofi_bottle` or the `swfsc_ichthyo` reference is re-staged (v2026.10.01 had 6 minted samples
on a cast; the 2026-10-04 re-stage had 7, because two casts of one station and date tie for the
same DIC row and `match_by_site_datetime()` has no tie-break). They are guarded by invariants
instead of pinned: the parts add up to the whole, every sample matching no cast with a depth
publishes its observations, no cast key is fabricated, and the arms hold exactly their rows.

```{r}
#| label: scope-assertions

  SELECT measurement_type, COUNT(*) AS n FROM dic_measurement WHERE depth_m IS NULL GROUP BY 1 ORDER BY 1")

  SELECT measurement_type, COUNT(*) AS n FROM dic_measurement

cat(glue("minted {d_scope$n_minted}: {d_scope$n_with_cast} on a cast, {d_scope$n_no_cast} matching no cast ",

cat(glue("obs: {format(n_obs_cast, big.mark = ',')} of matched casts; ",
```

### Cruise and ship resolution of the minted samples

A sample is keyed to a cruise only through a ship the SWFSC reference carries and a cruise it
holds for that ship; the rest are left NULL, never keyed to a cruise the reference does not
know (the release's `complete_cruise_reference()` derived-row ratchet only ever goes down).

```{r}
#| label: cruise-assertions

d_ck <- dbGetQuery(con, "
  SELECT COUNT(*) FILTER (WHERE parent_sample_key IS NULL AND cruise_key IS NOT NULL) AS n_no_cast_keyed,
         COUNT(*) FILTER (WHERE parent_sample_key IS NULL AND cruise_key IS NULL)     AS n_no_cast_null,
         COUNT(*) FILTER (WHERE parent_sample_key IS NOT NULL AND cruise_key IS NULL) AS n_cast_null
  FROM sample WHERE dataset_key = 'calcofi_dic'")
# The count depends on the `cruise` reference, so it is MEASURED, not pinned: measured
# 2026-10-04 on the 2026-09-26 ichthyo export (WS-1004X3): 2,920 keyed (span or month),
# 335 NULL on 8 EXPOCODEs (the named table below; 240 are NOAA Ship Sally Ride, 33P4,
# whose cruises the ichthyo export lacks). The guard is an invariant plus a ratchet:
#  * a sample is NULL only if its ship is not in the ship reference, or the reference holds
#    no cruise of that ship whose span (+/- 3 d) contains the date or whose key is the
#    event's month (what resolve_cruise_key() would have used): a key the reference does
#    hold must never be missed;
#  * the NULL count may only go DOWN from CRUISE_NULL_NO_CAST_MAX; lower it to the number
#    measured here whenever it falls (and the release's key_null_max for calcofi_dic).
CRUISE_NULL_NO_CAST_MAX <- 335L
n_null_resolvable <- dbGetQuery(con, "
  SELECT COUNT(*) FROM sample s
  JOIN dic_sample d ON s.sample_key = 'calcofi_dic:bottle:' || md5(concat_ws('|', d.expocode,
       CAST(d.datetime_start_utc AS VARCHAR), CAST(d.latitude AS VARCHAR),
       CAST(d.longitude AS VARCHAR), CAST(d.depth_m AS VARCHAR)))
  WHERE s.dataset_key = 'calcofi_dic' AND s.parent_sample_key IS NULL AND s.cruise_key IS NULL
    AND d.ship_key IS NOT NULL
    AND EXISTS (
      SELECT 1 FROM cruise c JOIN ship sh ON sh.ship_key = c.ship_key
      WHERE c.ship_key = d.ship_key
        AND (CAST(d.datetime_start_utc AS DATE)
               BETWEEN c.date_min - INTERVAL 3 DAY AND c.date_max + INTERVAL 3 DAY
             OR c.cruise_key = strftime(CAST(d.datetime_start_utc AS DATE), '%Y-%m') || '-' || sh.ship_nodc))")[[1]]
stopifnot(
  "a no-cast sample the reference could key must not be left NULL" = n_null_resolvable == 0,
  "NULL cruise_key on samples matching no cast may only go down (ratchet)" =
    d_ck$n_no_cast_null <= CRUISE_NULL_NO_CAST_MAX,
  # a sample on a matched cast carries that cast's own key; DIC adds no NULL of its own
  "a sample on a matched cast must carry the cast's own cruise_key" =
    d_ck$n_cast_null == dbGetQuery(con, "
      SELECT COUNT(*) FROM sample s JOIN casts c
        ON s.parent_sample_key = 'calcofi_bottle:cast:' || CAST(c.cast_id AS VARCHAR)
      WHERE s.dataset_key = 'calcofi_dic' AND c.cruise_key IS NULL")[[1]])
if (d_ck$n_no_cast_null < CRUISE_NULL_NO_CAST_MAX)
  cat(glue("NOTE: NULL cruise_key fell to {d_ck$n_no_cast_null}; lower CRUISE_NULL_NO_CAST_MAX ",
           "(was {CRUISE_NULL_NO_CAST_MAX})"), "\n")
cat(glue("cruise_key on minted DIC samples matching no cast: {d_ck$n_no_cast_keyed} keyed, ",
         "{d_ck$n_no_cast_null} NULL; {d_ck$n_cast_null} NULL on a matched cast"), "\n")

dbGetQuery(con, "
  SELECT d.expocode, MIN(d.ship_name) AS ship_name, MIN(d.ship_key) AS ship_key,
         COUNT(DISTINCT s.sample_key) AS n_samples,
         CASE WHEN MIN(d.ship_key) IS NULL THEN 'ship not in the SWFSC ship reference'
              ELSE 'no reference cruise for that ship and month' END AS why_null
  FROM sample s
  JOIN dic_sample d ON s.sample_key = 'calcofi_dic:bottle:' || md5(concat_ws('|', d.expocode,
       CAST(d.datetime_start_utc AS VARCHAR), CAST(d.latitude AS VARCHAR),
       CAST(d.longitude AS VARCHAR), CAST(d.depth_m AS VARCHAR)))
  WHERE s.dataset_key = 'calcofi_dic' AND s.parent_sample_key IS NULL AND s.cruise_key IS NULL
  GROUP BY d.expocode ORDER BY d.expocode") |>
  datatable(caption = "DIC cruises left without a cruise_key (calcofi_dic_07)")
```
