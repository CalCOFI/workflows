1 Overview

Hydrographic values derived from the CalCOFI Bottle Database rather than measured: spice and the TEOS-10 sigma-theta at every bottle, back to the start of the record (1949). Asked for by Nastassia Patin (spice at each bottle depth, 2026-10-16) and Rasmus Swalethorp (thread “calcofi derived data”, 2026-10-19: “keeping derived values in a separate dataset. Back calculating spice and sigma theta to the beginning using the values in the bottle database”); Ben Best’s reply (2026-10-20): “a separate bottle-derived dataset, back-calculated from the start of the record. From the bottle database’s own temperature and salinity … Spiciness and TEOS-10 sigma theta go in first.” The other bottle-derived values (IntC14, integrated chlorophyll) join this dataset once the DECODR source arrives.

  • Source: the calcofi_bottle ingest’s temperature (T_degC) and salinity (Salnty) per bottle, with their quality codes (T_qual, S_qual), its depth and its cast’s position — read from that ingest’s staged output when it is current, otherwise from the release (see Input).
  • The nitracline depth per bottle cast (nitracline_depth, sample_measurement on the cast’s sample_key): the depth at which nitrate reaches 1 µmol/L, interpolated linearly between the bottle above and the bottle below, by the CTD team’s bottle-era rule (Rasmus Swalethorp, 2026-09-24; his D_NClineDepth.m: calcofi4db::profile_threshold_depth()); a cast whose shallowest bottle is already at 1 µmol/L counts only when that bottle is within 20 m of the surface and the cast has three or more bottles. The same key is published from the CTD’s fitted nitrate estimate by calcofi_ctd-derived; filter by dataset_key.
  • The rule is one tested calcofi4db function, bottle_spice_sigma0(): sea pressure from depth and latitude (gsw_p_from_z), absolute salinity, conservative temperature, then gsw_spiciness0 (by ctd_spice(), the rule the CTD series uses) and gsw_sigma0. This notebook only applies it.
  • Flags first. A bottle whose temperature or salinity the provider flags 8 (suspect) or 9 (missing) gets neither value: a derived value carries no flag, so nothing downstream could undo a flagged input (measurement-bounds skill).
  • The legacy value stays. The bottle database’s own sigma_theta (computed by DECODR’s algorithm) is untouched in calcofi_bottle; sigma_theta_teos10 is the modern value beside it (Rasmus Swalethorp, 2026-10-16: “keep legacy, add modern, document”). Where the two disagree by more than 0.1 kg m⁻³ the bottle is listed for the provider (Findings).
  • A known-wrong input is flagged at its source, never withheld by name. Cruise 2021-05-3322’s salinity column holds sigma-theta (calcofi_bottle Q13); the provider answered on 2026-11-01 (“for now exclude the salinity data”), so calcofi_bottle sets its salinity to 8 (metadata/calcofi/bottle/qual_overrides.csv) and the flag rule above keeps every one of its bottles out. The notebook reports how many bottles the flags remove and asserts the cruise emits nothing.

7 Register Measurement Types

spiciness0 is reused under this dataset (Ben Best, D8, 2026-10-20): the same quantity by the same rule (ctd_spice()), so a reader filters one key by dataset_key. Its row is defined by calcofi_ctd-derived, which keeps the description, units, derivation and bound; this ingest only adds itself to the row’s _source_datasets (add_measurement_source_dataset()). sigma_theta_teos10 is new (D8): appended with register_measurement_types(), its registry-owned fields set with declare_measurement_fields(), its bound with declare_measurement_bounds(). It is not the bottle’s sigma_theta (DECODR’s legacy algorithm, labelled so in its own row) and it does not join that key’s variable: both come from the same bottles, and a crosswalk unifies series that are not the same physical samples.

No bound is invented or taken from the data. The sigma-theta bound is gsw_sigma0 over the bottle’s registered temperature × salinity bounds at 0 dbar, rounded outward — what the registry already calls physically possible (question Q02). The reused spiciness0 bound (−25 to 18, calcofi_ctd-derived Q07) is checked to cover the same grid.

## Overview

Hydrographic values **derived** from the CalCOFI Bottle Database rather than measured:
spice and the TEOS-10 sigma-theta at every bottle, back to the start of the record
(1949). Asked for by Nastassia Patin (spice at each bottle depth, 2026-10-16) and
Rasmus Swalethorp (thread "calcofi derived data", 2026-10-19: "keeping derived values
in a separate dataset. Back calculating spice and sigma theta to the beginning using
the values in the bottle database"); Ben Best's reply (2026-10-20): "a separate
bottle-derived dataset, back-calculated from the start of the record. From the bottle
database's own temperature and salinity … Spiciness and TEOS-10 sigma theta go in
first." The other bottle-derived values (IntC14, integrated chlorophyll) join this
dataset once the DECODR source arrives.

- **Source**: the `calcofi_bottle` ingest's `temperature` (`T_degC`) and `salinity`
  (`Salnty`) per bottle, with their quality codes (`T_qual`, `S_qual`), its depth and
  its cast's position — read from that ingest's staged output when it is current,
  otherwise from the release (see [Input](#input)).
- **The nitracline depth** per bottle cast (`nitracline_depth`, `sample_measurement` on
  the cast's `sample_key`): the depth at which nitrate reaches 1 µmol/L, interpolated
  linearly between the bottle above and the bottle below, by the CTD team's bottle-era
  rule (Rasmus Swalethorp, 2026-09-24; his `D_NClineDepth.m`:
  `calcofi4db::profile_threshold_depth()`); a cast whose shallowest bottle is already at
  1 µmol/L counts only when that bottle is within 20 m of the surface and the cast has
  three or more bottles. The same key is published from the CTD's fitted nitrate
  estimate by `calcofi_ctd-derived`; filter by `dataset_key`.
- **The rule is one tested calcofi4db function**, `bottle_spice_sigma0()`: sea pressure
  from depth and latitude (`gsw_p_from_z`), absolute salinity, conservative temperature,
  then `gsw_spiciness0` (by `ctd_spice()`, the rule the CTD series uses) and
  `gsw_sigma0`. This notebook only applies it.
- **Flags first.** A bottle whose temperature or salinity the provider flags 8
  (suspect) or 9 (missing) gets neither value: a derived value carries no flag, so
  nothing downstream could undo a flagged input (`measurement-bounds` skill).
- **The legacy value stays.** The bottle database's own `sigma_theta` (computed by
  DECODR's algorithm) is untouched in `calcofi_bottle`; `sigma_theta_teos10` is the
  modern value beside it (Rasmus Swalethorp, 2026-10-16: "keep legacy, add modern,
  document"). Where the two disagree by more than 0.1 kg m⁻³ the bottle is listed for
  the provider ([Findings](#findings)).
- **A known-wrong input is flagged at its source, never withheld by name.** Cruise
  2021-05-3322's salinity column holds sigma-theta (`calcofi_bottle` Q13); the provider
  answered on 2026-11-01 ("for now exclude the salinity data"), so `calcofi_bottle` sets
  its salinity to 8 (`metadata/calcofi/bottle/qual_overrides.csv`) and the flag rule
  above keeps every one of its bottles out. The notebook reports how many bottles the
  flags remove and asserts the cruise emits nothing.

## Register Measurement Types

`spiciness0` is **reused** under this dataset (Ben Best, D8, 2026-10-20): the same
quantity by the same rule (`ctd_spice()`), so a reader filters one key by
`dataset_key`. Its row is defined by `calcofi_ctd-derived`, which keeps the
description, units, derivation and bound; this ingest only adds itself to the row's
`_source_datasets` (`add_measurement_source_dataset()`). `sigma_theta_teos10` is
**new** (D8): appended with `register_measurement_types()`, its registry-owned fields
set with `declare_measurement_fields()`, its bound with
`declare_measurement_bounds()`. It is not the bottle's `sigma_theta` (DECODR's legacy
algorithm, labelled so in its own row) and it does not join that key's `variable`:
both come from the same bottles, and a crosswalk unifies series that are not the same
physical samples.

**No bound is invented or taken from the data.** The sigma-theta bound is
`gsw_sigma0` over the bottle's registered temperature × salinity bounds at 0 dbar,
rounded outward — what the registry already calls physically possible (question
Q02). The reused `spiciness0` bound (−25 to 18, `calcofi_ctd-derived` Q07) is checked

## Findings for the Provider {#findings}

Values inside the generous bounds are **not deleted**: a bound catches the impossible.
Two lists go to the provider (question Q03): bottles where the TEOS-10 sigma-theta and
the bottle database's own (legacy, DECODR) sigma-theta differ by more than
`r diff_list_kg_m3` kg m⁻³ — a gap that size is not the algorithm, it is one of the
inputs (a temperature or salinity the legacy value was not computed from) — and spice
below −3 kg m⁻³, which needs a practical salinity near 20, the same class of fault the
CTD derived products list (`calcofi_ctd-derived` Q08).

Cruise 2021-05-3322 is not in these lists because its salinity is **flagged 8** (see
Compute the Products): at the first render (2026-10-20) it was 918 of the 928 bottles past
0.1 kg m⁻³ and every bottle with spice below −3, because on every bottle the published
salinity equals the bottle's own sigma-theta (`calcofi_bottle` Q13). Its source code is
blank (good, by `calcofi_bottle` Q01) and the values sit inside the generous bounds, so
neither caught it; it was withheld by name from 2026-10-20 until the provider answered
Q13 on 2026-11-01, and is now flagged at the source. The two 2020-07-33P4 surface bottles
of `calcofi_bottle` Q17 left these lists the same way.

## Validate

`validate_for_release()` treats every `_key` column as required. The NULLs below are
declared with their reason and count; anything undeclared, or a count that moved,
fails the render.

```{r}
#| label: validate
# the expected NULL counts, derived independently of the table being checked (from
# the source bottles that got a value, not from obs)
n_exp <- dbGetQuery(con, "
  SELECT COUNT(*) AS n_obs,
         2 * SUM(CASE WHEN b.grid_key IS NULL THEN 1 ELSE 0 END) AS n_grid_null,
         2 * SUM(CASE WHEN b.cruise_key IS NULL THEN 1 ELSE 0 END) AS n_cruise_null
  FROM btl b JOIN derived x USING (sample_key) WHERE x.sigma_theta_teos10 IS NOT NULL")
# the wrangling tables are not outputs; drop them so the validator sees what ships. The
# src_* inputs are views (stage) or tables (release), and DuckDB refuses DROP VIEW on a
# table, so each is dropped as what it is
for (tb in c("btl", "derived", "nitracline", "src_obs", "src_sample")) {
  kind <- dbGetQuery(con, glue(
    "SELECT table_type FROM information_schema.tables WHERE table_name = '{tb}'"))$table_type
  if (length(kind))
    dbExecute(con, glue("DROP {if (grepl('VIEW', kind[1])) 'VIEW' else 'TABLE'} IF EXISTS {tb}"))
}
results <- validate_for_release(con, checks = "all", strict = FALSE)
nullable <- tribble(
  ~table, ~column,      ~n,                       ~reason,
  "obs",  "taxon_key",  2 * n_exp$n_obs,          "env realm: a derived physical quantity names no organism",
  "obs",  "grid_key",   n_exp$n_grid_null,        "inherited: the calcofi_bottle cast has no grid cell",
  "obs",  "cruise_key", n_exp$n_cruise_null,      "inherited: the calcofi_bottle cast's cruise is not resolved") |>
  filter(n > 0)
found <- tibble(msg = results$errors) |>
  mutate(table  = sub("^Table '([^']+)'.*$", "\\1", msg),
         column = sub("^.*required column '([^']+)'.*$", "\\1", msg),
         n      = suppressWarnings(as.integer(sub("^Table '[^']+' has (\\d+) NULL.*$", "\\1", msg))))
unexplained <- anti_join(found, nullable, by = c("table", "column"))
moved <- inner_join(found, nullable, by = c("table", "column"), suffix = c("", "_decl")) |>
  filter(!is.na(n_decl), n != n_decl)
nullable |> left_join(select(found, table, column, n_found = n), by = c("table", "column")) |>
  datatable(caption = "Declared NULLs vs what validate_for_release() found", rownames = FALSE)
if (nrow(unexplained)) print(unexplained$msg)
stopifnot(
  "a NULL appeared with no declared reason" = nrow(unexplained) == 0,
  "a declared NULL count has changed"       = nrow(moved) == 0)
```
