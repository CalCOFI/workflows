1 Overview

Source: EDI package knb-lter-cce.253.3 (Aluwihare), entity TOC (table_253.csv): 10,150 rows, 13 columns, 22 cruises from 2008-03 to 2017-08. Fetched by libs/download_toc.R, revision and md5 pinned. Licence: CC0 1.0 (the EML’s intellectualRights).

  • Provider: cce-lter (same as iron, poc-pon).
  • Grain: one sample per Niskin bottle, keyed by the source’s own (studyName, Cast Number, Bottle number). A bottle can carry more than one TOC value: 46 bottles have 2 rows and 4 have 4. Each row is published as its own obs (a replicate analysis), not averaged (Q02).
  • Realm: env. One measurement type, toc, in µmol/L. TOC is dissolved plus particulate organic carbon; the provider reports TOC rather than DOC for this region (see the abstract).
  • Precision: TOC CV (%) is the coefficient of variation (SD / mean x 100, Q03), so each value’s standard deviation, TOC x CV / 100 in µmol/L, is published as obs.measurement_prec (NULL on the 59 rows with no CV).
  • Not published (kept in the archived source): Associated Bottle number (Q04).
  • Cleaned before publishing (each counted and asserted below):
    • 2 rows that repeat another row in every column are dropped.
    • 1 row with no date (0000-00-00), no position and depth NULL is held out (Q05).
  • High values: 13 values lie between 2,077 and 2,208 µmol/L, the range of seawater inorganic carbon, 20 to 60 times the median. They are published as-is (no upper bound is declared) and are the subject of Q01.
  • Cruise key: ship code from studyName plus the source’s Cruise designation (YYYYMM), via derive_cruise_key_on_casts().
  • Bottle match (evidence only): same as poc-pon; calcofi_bottle cast by site_key within 1 day, then the Niskin bottle within 2 m of the target depth. Not published, not a parent.

4 Clean, Type-Cast

  1. Exact duplicates. 2 rows repeat another row in every column and are dropped.
  2. Undated row. One row (2009-01-08-C-32NM, line 93.3 station 60, cast 11 bottle 19) has the date 0000-00-00 00:00:00, no position and depth NULL. It is held out (Q05).

No -999 sentinel occurs; the only non-numeric measurement-side value is that one NULL depth (asserted).

d_meas <- d_rows |>
  inner_join(d_sample |> select(sample_key_id, sample_id), by = "sample_key_id") |>
  arrange(sample_id, toc_umol_l) |>
  transmute(
    measurement_id    = row_number(),
    sample_id,
    measurement_type  = "toc",
    measurement_value = toc_umol_l,

    measurement_prec  = toc_umol_l * toc_cv_pct / 100,

## Overview

**Source**: EDI package `knb-lter-cce.253.3` (Aluwihare), entity *TOC*
(`table_253.csv`): 10,150 rows, 13 columns, **22** cruises from 2008-03 to
2017-08. Fetched by
`libs/download_toc.R`, revision and md5 pinned. Licence: CC0 1.0 (the EML's
`intellectualRights`).

- **Provider**: `cce-lter` (same as `iron`, `poc-pon`).
- **Grain**: one `sample` per Niskin bottle, keyed by the source's own
  `(studyName, Cast Number, Bottle number)`. A bottle can carry more than one
  TOC value: 46 bottles have 2 rows and 4 have 4. Each row is published as its
  own `obs` (a replicate analysis), not averaged (Q02).
- **Realm**: `env`. One measurement type, `toc`, in µmol/L. TOC is dissolved
  plus particulate organic carbon; the provider reports TOC rather than DOC for
  this region (see the abstract).
- **Precision**: `TOC CV (%)` is the coefficient of variation (SD / mean x 100,
  Q03), so each value's standard deviation, `TOC x CV / 100` in µmol/L, is
  published as `obs.measurement_prec` (NULL on the 59 rows with no CV).
- **Not published** (kept in the archived source): `Associated Bottle number`
  (Q04).
- **Cleaned before publishing** (each counted and asserted below):
  - 2 rows that repeat another row in every column are dropped.
  - 1 row with no date (`0000-00-00`), no position and depth `NULL` is held out
    (Q05).
- **High values**: 13 values lie between 2,077 and 2,208 µmol/L, the range of
  seawater *inorganic* carbon, 20 to 60 times the median. They are published
  as-is (no upper bound is declared) and are the subject of Q01.
- **Cruise key**: ship code from `studyName` plus the source's `Cruise`
  designation (YYYYMM), via `derive_cruise_key_on_casts()`.
- **Bottle match** (evidence only): same as `poc-pon`; `calcofi_bottle` cast by
  `site_key` within 1 day, then the Niskin bottle within 2 m of the target depth.
  Not published, not a parent.

| source | core | transform |
|---|---|---|
| `toc_sample` | `sample` (`bottle`) | one row per bottle; key `cce-lter_toc:bottle:{studyName}-{Cast Number}-{Bottle number}`; `depth_min_m = depth_max_m = Depth (m)` (the target depth); time = `Datetime GMT`; `cruise_key` from ship code + `Cruise` |
| `Total Organic Carbon (µmol/L)` | `obs` `toc` | verbatim, µmol/L; one obs per source row, so a bottle with replicate analyses has 2 or 4 |
| `TOC CV (%)` | `obs.measurement_prec` | `TOC x CV / 100`: the value's standard deviation in µmol/L (CV = SD / mean x 100, Q03); NULL where the CV is blank |
| `Associated Bottle number` | -- | **not published** (Q04) |
| matched `calcofi_bottle` cast/bottle | -- | **not published**: evidence only, not `parent_sample_key` |
| 2 exact-duplicate rows, 1 undated row | -- | dropped / held out (Q05) |

## Check Declared Bounds

`toc` is registered with `valid_min = 0` only (a concentration cannot be
negative). No upper bound is declared, so nothing is dropped for being high:
the 13 values near 2,100 µmol/L are published as-is until the provider answers
Q01. A one-sided bound counts as declared, so this check reports `ok`.

```{r}
#| label: bounds-check
bounds_pre <- check_measurement_bounds(con, "toc_measurement", mt = d_meas_type)
bounds_datatable(bounds_pre)

oob_tally <- drop_out_of_bounds(con, "toc_measurement", mt = d_meas_type)
cat(glue(
  "out-of-range rows removed: {format(sum(oob_tally$n_bad %||% 0), big.mark=',')} ",
  "(only valid_min = 0 is declared)"), "\n")

bounds_post <- check_measurement_bounds(
  con, "toc_measurement", mt = d_meas_type, include_undeclared = FALSE)
stopifnot(
  "toc_measurement must hold no value outside a DECLARED bound" =
    sum(bounds_post$status == "out_of_range") == 0)
```

```{r}
#| label: emit_core
append_sample(con, sample_arm_self(
  ds_key, "toc_sample", "sample_key_id", "bottle",
  dt_col = "datetime_start_utc", site_expr = "site_key",
  depth_min = "depth_m", depth_max = "depth_m"))

append_obs(con, glue("
  SELECT 'env', '{ds_key}', {ns_key(ds_key, 'bottle', 's.sample_key_id')},
         s.grid_key, s.cruise_key, s.latitude, s.longitude,
         CAST(s.datetime_start_utc AS TIMESTAMP), s.depth_m, s.depth_m,
         NULL::VARCHAR, NULL::VARCHAR, m.measurement_type, m.measurement_value,
         NULL::VARCHAR, m.measurement_prec
  FROM toc_measurement m
  JOIN toc_sample s USING (sample_id)"))

q1 <- function(sql) dbGetQuery(con, sql)[[1]]
core <- list(
  sample = q1("SELECT COUNT(*) FROM sample"),
  obs    = q1("SELECT COUNT(*) FROM obs"))
cat(glue("core projection -- sample={core$sample} obs={core$obs}"), "\n")

src_total <- q1("SELECT SUM(measurement_value) FROM toc_measurement")
obs_total <- q1(glue("SELECT SUM(measurement_value) FROM obs WHERE dataset_key = '{ds_key}'"))
stopifnot(
  "one sample per bottle" = core$sample == nrow(d_sample),
  "obs is one row per TOC analysis" = core$obs == q1("SELECT COUNT(*) FROM toc_measurement"),
  "obs value total equals the source" = isTRUE(all.equal(obs_total, src_total)),
  "only toc is emitted" =
    identical(dbGetQuery(con, glue("SELECT DISTINCT measurement_type FROM obs
                                    WHERE dataset_key = '{ds_key}'"))$measurement_type, "toc"),
  "sample_key is unique" =
    q1(glue("SELECT COUNT(*) - COUNT(DISTINCT sample_key) FROM sample
             WHERE dataset_key = '{ds_key}'")) == 0,
  "every obs.sample_key resolves in sample" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN sample s USING (sample_key)
        WHERE s.sample_key IS NULL") == 0,
  "every obs.measurement_type resolves in measurement_type" =
    q1("SELECT COUNT(*) FROM obs o LEFT JOIN measurement_type t USING (measurement_type)
        WHERE t.measurement_type IS NULL") == 0)

invisible(dbExecute(con, "DROP TABLE IF EXISTS toc_measurement_src"))
invisible(dbExecute(con, "ALTER TABLE toc_measurement RENAME TO toc_measurement_src"))
invisible(dbExecute(con, glue(
  "CREATE OR REPLACE VIEW toc_measurement AS
   SELECT o.obs_id AS measurement_id,
          o.sample_key,
          substr(o.sample_key, length('{ds_key}:bottle:') + 1) AS sample_key_id,
          o.measurement_type, o.measurement_value, o.measurement_qual
   FROM obs o WHERE o.dataset_key = '{ds_key}'")))
```
