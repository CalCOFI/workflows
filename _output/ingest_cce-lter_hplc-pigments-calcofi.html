1 Overview

Source: EDI package knb-lter-cce.316.1 (Goericke, Stukel, Dovel), entity ChromatographyPigmentsCalCOFI (table_324.csv; DataZoo dataset 316): 9,153 rows, 60 columns, 81 CalCOFI cruises from 2002-03 to 2023-04. Fetched by libs/download_hplc_pigments_calcofi.R, revision and md5 pinned. Licence: CC0 1.0 (the EML’s intellectualRights).

This is the CalCOFI-cruise HPLC table. The CCE Process-cruise HPLC table (EDI knb-lter-cce.72) is a separate holding (cce-lter_hplc-pigments), not ingested here.

  • Provider: cce-lter.
  • Grain: one row per HPLC analysis of a Niskin bottle; the sample is the bottle, keyed {studyName}-{Cast Number}-{Bottle Number}. Seven bottles carry two analyses with different values (replicates, Q03); both are published as separate obs of the one sample, as in the TOC ingest.
  • Two labs, two sets of measurement types. Samples from 2002-2014 were run by the Goericke Lab (SIO), from 2014 on by Horn Point Laboratory (UMCES); 31 bottles in 2014 were run by both. The provider’s own comparison (EML methods) finds some pigments comparable between labs and others not (neoxanthin and prasinoxanthin run higher at UMCES; carotene is defined differently). So each lab’s columns get their own type, hplc_{pigment}_sio and hplc_{pigment}_umces (44 types, metadata/cce-lter/hplc-pigments-calcofi/pigment_columns.csv), the same way CTD sensor pairs are kept apart. Joining the comparable ones is a variable crosswalk decision, not made here.
  • Realm: env, µg/L. The provider’s Quality Control flag (0-3, metadata/measurement_qual.csv code set hplc-pigments-calcofi) is carried on every obs of the row as measurement_qual.
  • Not published: Total chlorophyll b and Total Chlorophyll c for both labs (sums of published pigments; asserted), Gyroxanthin diester (UMCES) (empty), Associated Bottle Number (Q05). Total chlorophyll a is published: it is the provider’s headline biomass value and the basis of its QC flags, and the UMCES total differs from the sum of its parts by rounding.
  • Held out (each counted and asserted below):
    • 2 rows: one bottle listed at two depths (2005-11 cast 25 bottle 20, 1 m vs 2 m), the same conflict as cce-lter_poc-pon Q02 (Q01).
    • 8 rows: two bottles each listed four times, two sets of values crossed with QC flags 0 and 3, so which flag belongs to which value is unknown (Q02).
    • 1 value: Carotene (Goericke_SIO) = 10,575 µg/L on 2013-11 cast 41 bottle 19 (QC flag 2; the next-highest is 0.64 µg/L). The rest of that row is published (Q04).
  • Cruise key: from the ship code in studyName (translated to NODC through metadata/ship_renames.csv, including CCE-LTER’s 33SH for the 2021-05 Bell M. Shimada cruise), the sample time and each cruise’s designated month, by derive_cruise_key_on_casts(). This table has no Cruise column, so the designation comes from cruise_designation.csv (the same cruises’ Cruise column in the POC/PON and TOC tables, or the SWFSC cruise for the 11 those tables lack). Without it, 701 samples on cruises with no date span fell back to the sample’s own month, and 20 on the 2023-03-25 Shimada cruise were keyed to a cruise that does not exist (2023-03-3322 rather than 2023-04-3322).

4.2 Totals agree with their parts

The provider defines TChl a = Chl a + DVChl a + Chlide a for both labs, and the total chl b and chl c columns as sums of their parts. Totals b and c are not published because they follow from published pigments; that is checked here. A blank part counts as 0 (the provider’s own sums treat it so). UMCES values are rounded to 0.001 µg/L, so their sums agree to within rounding.

6 Resolve Ship and Cruise Keys

This table has no Cruise designation column, so the cruise’s designated month comes from metadata/cce-lter/hplc-pigments-calcofi/cruise_designation.csv: the Cruise column the POC/PON (EDI 54) and TOC (EDI 253) tables give the same studyName, or, for the 11 cruises neither has, the SWFSC cruise whose dates hold it. A sample is keyed by the cruise whose dates hold it (span), else by that designation; never by its own month, which split the 2023-03-25 Shimada cruise across two months on the first render.

## Overview

**Source**: EDI package `knb-lter-cce.316.1` (Goericke, Stukel, Dovel), entity
*ChromatographyPigmentsCalCOFI* (`table_324.csv`; DataZoo dataset 316): 9,153
rows, 60 columns, 81 CalCOFI cruises from 2002-03 to 2023-04. Fetched by
`libs/download_hplc_pigments_calcofi.R`, revision and md5 pinned. Licence: CC0 1.0
(the EML's `intellectualRights`).

This is the **CalCOFI-cruise** HPLC table. The CCE Process-cruise HPLC table
(EDI `knb-lter-cce.72`) is a separate holding (`cce-lter_hplc-pigments`), not
ingested here.

- **Provider**: `cce-lter`.
- **Grain**: one row per HPLC analysis of a Niskin bottle; the sample is the
  bottle, keyed `{studyName}-{Cast Number}-{Bottle Number}`. Seven bottles carry
  two analyses with different values (replicates, Q03); both are published as
  separate obs of the one sample, as in the TOC ingest.
- **Two labs, two sets of measurement types.** Samples from 2002-2014 were run by
  the Goericke Lab (SIO), from 2014 on by Horn Point Laboratory (UMCES); 31
  bottles in 2014 were run by both. The provider's own comparison (EML methods)
  finds some pigments comparable between labs and others not (neoxanthin and
  prasinoxanthin run higher at UMCES; carotene is defined differently). So each
  lab's columns get their own type, `hplc_{pigment}_sio` and
  `hplc_{pigment}_umces` (44 types, `metadata/cce-lter/hplc-pigments-calcofi/pigment_columns.csv`),
  the same way CTD sensor pairs are kept apart. Joining the comparable ones is a
  `variable` crosswalk decision, not made here.
- **Realm**: `env`, µg/L. The provider's `Quality Control flag` (0-3,
  `metadata/measurement_qual.csv` code set `hplc-pigments-calcofi`) is carried on
  every obs of the row as `measurement_qual`.
- **Not published**: `Total chlorophyll b` and `Total Chlorophyll c` for both
  labs (sums of published pigments; asserted), `Gyroxanthin diester (UMCES)`
  (empty), `Associated Bottle Number` (Q05). `Total chlorophyll a` **is**
  published: it is the provider's headline biomass value and the basis of its QC
  flags, and the UMCES total differs from the sum of its parts by rounding.
- **Held out** (each counted and asserted below):
  - 2 rows: one bottle listed at two depths (2005-11 cast 25 bottle 20, 1 m vs
    2 m), the same conflict as `cce-lter_poc-pon` Q02 (Q01).
  - 8 rows: two bottles each listed four times, two sets of values crossed with QC
    flags 0 and 3, so which flag belongs to which value is unknown (Q02).
  - 1 value: `Carotene (Goericke_SIO)` = 10,575 µg/L on 2013-11 cast 41 bottle
    19 (QC flag 2; the next-highest is 0.64 µg/L). The rest of that row is
    published (Q04).
- **Cruise key**: from the ship code in `studyName` (translated to NODC through
  `metadata/ship_renames.csv`, including CCE-LTER's `33SH` for the 2021-05 Bell
  M. Shimada cruise), the sample time and each cruise's designated month, by
  `derive_cruise_key_on_casts()`. This table has no `Cruise` column, so the
  designation comes from `cruise_designation.csv` (the same cruises' `Cruise`
  column in the POC/PON and TOC tables, or the SWFSC cruise for the 11 those
  tables lack). Without it, 701 samples on cruises with no date span fell back
  to the sample's own month, and 20 on the 2023-03-25 Shimada cruise were keyed
  to a cruise that does not exist (2023-03-3322 rather than 2023-04-3322).

### Keys listed more than once

Ten bottles appear on more than one row. They fall in three groups, each counted
and asserted:

1. **Conflicting depth** (1 bottle, 2 rows): 2005-11-04-C-32NM cast 25 bottle 20,
   at 1 m and 2 m with identical values. Held out (Q01).
2. **Flag-crossed** (2 bottles, 8 rows): each listed four times, two sets of
   values each paired with QC flag 0 and with flag 3. Held out (Q02).
3. **Replicates** (7 bottles, 14 rows): two rows that agree on time, position,
   depth, associated bottle and QC flag but differ in pigment values. Both kept

### Totals agree with their parts

The provider defines `TChl a = Chl a + DVChl a + Chlide a` for both labs, and
the total chl b and chl c columns as sums of their parts. Totals b and c are not
published because they follow from published pigments; that is checked here. A
blank part counts as 0 (the provider's own sums treat it so). UMCES values are
rounded to 0.001 µg/L, so their sums agree to within rounding.

```{r}
#| label: totals-check
pc <- function(src) d_row[[pig_col[d_pig$source_column == src]]]
z  <- function(x) coalesce(x, 0)
max_diff <- function(tot, parts) max(abs(tot - parts), na.rm = TRUE)
d_tot <- tribble(
  ~total, ~max_abs_diff,
  "TChl a (SIO)",   max_diff(pc("Total chlorophyll a (Goericke_SIO)"),
                             z(pc("Chlorophyll a (Goericke_SIO)")) + z(pc("Divinyl chlorophyll a (Goericke_SIO)")) + z(pc("Chlorophyllide a (Goericke_SIO)"))),
  "TChl a (UMCES)", max_diff(pc("Total chlorophyll a (UMCES)"),
                             z(pc("Chlorophyll a (UMCES)")) + z(pc("Divinyl chlorophyll a (UMCES)")) + z(pc("Chlorophyllide a (UMCES)"))),
  "TChl b (SIO)",   max_diff(pc("Total chlorophyll b (Goericke_SIO)"), z(pc("Chlorophyll b (Goericke_SIO)"))),
  "TChl b (UMCES)", max_diff(pc("Total Chlorophyll b (UMCES)"),
                             z(pc("Chlorophyll b (UMCES)")) + z(pc("Divinyl Chlorophlyll b (UMCES)"))),
  "TChl c (SIO)",   max_diff(pc("Total Chlorophyll c (Goericke_SIO)"),
                             z(pc("Chlorophyll c (Goericke_SIO)")) + z(pc("Chlorophyll c 1 (Goericke_SIO)")) +
                             z(pc("Chlorophyll c 2 (Goericke_SIO)")) + z(pc("Chlorophyll c 3 (Goericke_SIO)"))),
  "TChl c (UMCES)", max_diff(pc("Total Chlorophyll c (UMCES)"),
                             z(pc("Chlorophyll c 12 (UMCES)")) + z(pc("Chlorophyll c 3 (UMCES)"))))
d_tot |> datatable(caption = "Largest |total - sum of parts| (ug/L)", rownames = FALSE)
stopifnot(

    all(d_tot$max_abs_diff[str_detect(d_tot$total, "SIO")] < 1e-9),
```
