1 Overview

Build one Darwin Core Archive per biological dataset in the frozen release — event.csv (Event core) + occurrence.csv + extendedMeasurementOrFact.csv + meta.xml + the release’s own eml/{dataset_key}.xml — validate it, and write it to data/darwincore/{dataset_key}/{dataset_key}_{version}.zip with a manifest.

This notebook writes files only. The upload to the OBIS-USA IPT is a deliberate manual act with Ben’s login, gated on a content change (Decision 10; docs/portals.qmd § OBIS has the steps). Nothing here talks to a portal except the read-only duplicate check below.

1.1 Why it is generic now

publish_ichthyo_to-obis.qmd was the last per-dataset publisher. It read the swfsc_ichthyo source tables (ichthyo, net, tow, site, species, lookup) and hand-built the Event / Occurrence / eMoF triple, which is why nine other biological datasets had no OBIS route at all — and why, since the core consolidation retired those tables from the release, it can no longer run.

Everything it hand-built now exists generically, and the vocabulary ids it was missing live in the registries the release already publishes:

1.2 occurrenceStatus is emitted honestly

ImportantAn absence is a claim about a protocol, not about a table

calcofi4db::dwc_absence_rule() measures which rule each dataset falls under:

  • zeros_recorded — the dataset has zero-valued obs_bio rows, so a sample examined and found empty of a taxon is already in the release. Those rows become occurrenceStatus = "absent", and nothing is derived.
  • positive_only — the dataset has no zero rows: a surveyed-empty sample simply has no row. Every row it does have is present, and an absence can only be derived, from sample_root minus the positives — which is true only if the protocol sorted every sample for the dataset’s whole vocabulary.

That last claim is about the protocol, not about the data, so deriving absences is never the default. For swfsc_ichthyo it would be plainly false: the ichthyoplankton protocol identifies each specimen to the lowest taxon possible, so 963 observed taxa × 61,104 sorted stations is 58 M absences nobody ever asserted. dwc_occurrence() refuses to emit them without absences = "sample_root" and a max_absences the caller raised on purpose.

The two positive-only datasets where the claim may genuinely hold — cce-lter_euphausiids (BTEDB stages 37 species in every sample) and sio_mesopelagic-fish (90 taxa, 102 tows) — are questions for their providers, not something this notebook decides. Until a provider says yes, they publish presence-only, which is what OBIS assumes of an archive with no absent rows.

rel_urls <- function(table) {
  src <- calcofi4r::cc_release_sources(rel_catalog, table)
  sf <- src$single_file
  # `single_file` is NA for a table with no whole-table twin, and as.character(NA)
  # is the STRING "NA" — which nzchar() happily accepts and read_parquet() then
  # resolves to a file called "NA". Test is.na() first, always.
  if (!is.null(sf) && length(sf) == 1 && !is.na(sf) && nzchar(as.character(sf)))
    return(as.character(sf))
  as.character(src$urls)
}

obis_search <- function(terms) {
  # OBIS's dataset search, read-only. The CalCOFI record is NOT findable by the
  # word "CalCOFI" (measured, 2026-09-05 — that is why distribution.csv carries
  # its id), so institution and taxon words are what is asked here.
  out <- lapply(terms, function(tm) {
    u <- glue("https://api.obis.org/v3/dataset?q={utils::URLencode(tm, reserved = TRUE)}&size=25")
    j <- tryCatch(jsonlite::fromJSON(u, simplifyVector = FALSE), error = function(e) NULL)
    r <- if (is.null(j)) list() else j$results
    if (!length(r)) return(NULL)
    tibble(
      term    = tm,
      obis_id = vapply(r, function(x) x$id %||% NA_character_, ""),
      title   = vapply(r, function(x) x$title %||% NA_character_, ""),
      owner   = vapply(r, function(x)
        paste(unlist(lapply(x$institutes %||% list(), function(i) i$name)), collapse = "; "), ""),
      records = vapply(r, function(x) as.numeric(x$records %||% NA), numeric(1)),
      published = vapply(r, function(x) as.character(x$published %||% NA), ""))
  })
  bind_rows(out)
}

An archive is a function of the dataset’s rows in the tables the Darwin Core builders read, its catalog record, the three registries, the portal ids it names, and this code. An unchanged fingerprint with its zip on disk is reused.

## Overview

Build one **Darwin Core Archive** per biological dataset in the frozen release —
`event.csv` (Event core) + `occurrence.csv` + `extendedMeasurementOrFact.csv` +
`meta.xml` + the release's own `eml/{dataset_key}.xml` — validate it, and write it
to `data/darwincore/{dataset_key}/{dataset_key}_{version}.zip` with a manifest.

This notebook **writes files only**. The upload to the OBIS-USA IPT is a
deliberate manual act with Ben's login, gated on a content change (Decision 10;
`docs/portals.qmd` § OBIS has the steps). Nothing here talks to a portal except
the read-only duplicate check below.

### Why it is generic now

`publish_ichthyo_to-obis.qmd` was the last per-dataset publisher. It read the
`swfsc_ichthyo` **source** tables (`ichthyo`, `net`, `tow`, `site`, `species`,
`lookup`) and hand-built the Event / Occurrence / eMoF triple, which is why nine
other biological datasets had no OBIS route at all — and why, since the core
consolidation retired those tables from the release, it can no longer run.

Everything it hand-built now exists generically, and the vocabulary ids it was
missing live in the registries the release already publishes:

### `occurrenceStatus` is emitted honestly

::: {.callout-important title="An absence is a claim about a protocol, not about a table"}
`calcofi4db::dwc_absence_rule()` measures which rule each dataset falls under:

* **`zeros_recorded`** — the dataset has zero-valued `obs_bio` rows, so a sample
  examined and found empty of a taxon is already in the release. Those rows become
  `occurrenceStatus = "absent"`, and nothing is derived.
* **`positive_only`** — the dataset has **no** zero rows: a surveyed-empty sample
  simply has no row. Every row it does have is `present`, and an absence can only be
  *derived*, from `sample_root` minus the positives — which is true only if the
  protocol sorted every sample for the dataset's whole vocabulary.

That last claim is about the protocol, not about the data, so deriving absences is
never the default. For `swfsc_ichthyo` it would be plainly false: the ichthyoplankton
protocol identifies each specimen to the lowest taxon possible, so 963 observed taxa
× 61,104 sorted stations is 58 M absences nobody ever asserted. `dwc_occurrence()`
refuses to emit them without `absences = "sample_root"` and a `max_absences` the
caller raised on purpose.

The two positive-only datasets where the claim may genuinely hold —
`cce-lter_euphausiids` (BTEDB stages 37 species in every sample) and
`sio_mesopelagic-fish` (90 taxa, 102 tows) — are **questions for their providers**,
not something this notebook decides. Until a provider says yes, they publish
presence-only, which is what OBIS assumes of an archive with no `absent` rows.
:::

```{r}
rel_urls <- function(table) {
  src <- calcofi4r::cc_release_sources(rel_catalog, table)
  sf <- src$single_file
  # `single_file` is NA for a table with no whole-table twin, and as.character(NA)
  # is the STRING "NA" — which nzchar() happily accepts and read_parquet() then
```

not rebuild this one). An unchanged fingerprint with its zip on disk is reused.

## Build every archive

```{r}
#| label: build
results <- list()
findings <- list()
data_changed <- list()

for (k in plan$dataset_key) {
  cat(glue("\n--- {k} ---"), "\n")
  d_dir <- file.path(OUT_DIR, k)

  # content-addressed, as the release's own tables are (calcofi4db::publish_fingerprint()):
  # an archive whose content_hash the previous manifest records EXISTS — nothing is built or
  # staged, it keeps its since and path, only checked_version moves. The previous manifest is
  # this machine's, else the one the bucket serves.
  prev_man <- file.path(OUT_DIR, glue("{k}_manifest.json"))
  pm <- if (file.exists(prev_man)) jsonlite::fromJSON(prev_man, simplifyVector = FALSE) else
    tryCatch(jsonlite::fromJSON(glue("{DWCA_HTTPS}/{k}/{k}_manifest.json"), simplifyVector = FALSE),
             error = function(e) NULL)
  ch <- fps[[k]]$content_hash
  # (a manifest from before content-addressing has no since; its content_hash was the CSVs' md5)
  if (!is.null(pm$since) && identical(pm$content_hash %||% "", ch)) {
    pm$checked_version <- RELEASE
    writeLines(jsonlite::toJSON(pm, auto_unbox = TRUE, pretty = TRUE, null = "null"), prev_man)
    cat(glue("content {substr(ch, 1, 12)} unchanged since {pm$since %||% pm$version} — {pm$path} exists"), "\n")
    results[[k]] <- tibble(dataset_key = k, status = "exists", built_from = pm$since %||% pm$version,
                           n_event = pm$counts$event %||% NA_integer_,
                           n_occurrence = pm$counts$occurrence %||% NA_integer_,
                           n_emof = pm$counts$emof %||% NA_integer_,
                           content_hash = ch, archive = pm$archive)
    next
  }
  prior_parts <- unlist(pm$input_fingerprint$parts)
  data_moved <- names(fps[[k]]$parts)[startsWith(names(fps[[k]]$parts), "data:") &
                  !(fps[[k]]$parts %in% prior_parts[names(fps[[k]]$parts)])]
  moved <- if (length(data_moved)) paste(data_moved, collapse = ", ") else "none (metadata or format only)"
  cat(glue("new content {substr(ch, 1, 12)}",
           "{if (!is.null(pm)) paste0(' (previous build ', pm$version, '; data changed in: ', moved, ')') else ''}"), "\n")
  data_changed[[k]] <- if (is.null(pm)) NA_character_ else moved

  ev <- dwc_event(con, k, gear = reg$gear, measurement_type = reg$measurement_type)
  oc <- dwc_occurrence(con, k, life_stage = reg$life_stage,
                       measurement_type = reg$measurement_type)
  mf <- dwc_emof(con, k, occurrence = oc, measurement_type = reg$measurement_type,
                 env = TRUE)

  chk <- dwc_check(ev, oc, mf, dataset_key = k)
  findings[[k]] <- chk
  print(chk[, c("finding", "level", "n", "detail")], row.names = FALSE)

  if (any(chk$level == "error")) {
    # a failing dataset gets NO zip: a broken archive at OBIS is worse than a
    # missing one, and the finding is what says why
    cat(glue("SKIPPED — {sum(chk$level == 'error')} error finding(s); no archive written"), "\n")
    results[[k]] <- tibble(dataset_key = k, status = "failed checks", built_from = RELEASE,
                           n_event = nrow(ev), n_occurrence = nrow(oc), n_emof = nrow(mf),
                           content_hash = NA_character_, archive = NA_character_)
    next
  }

  ipt <- dist |> filter(dataset_key == k, portal == "ipt") |> pull(id)
  obs_id <- dist |> filter(dataset_key == k, portal == "obis") |> pull(id)
  # the archive is named for the release its content first appeared in (since = this
  # release, being new) and lives in its content_hash directory
  obj_rel <- publish_object_path("dwca", k, ch, glue("{k}_{RELEASE}.zip"))
  a <- dwc_archive(
    d_dir, ev, oc, mf,
    eml_path        = eml_path_of(k),
    dataset_key     = k,
    version         = RELEASE,
    zip_path        = file.path(OUT_DIR, sub("^publish/dwca/", "", obj_rel)),
    ipt_resource    = if (length(ipt)) ipt[1] else NULL,
    obis_dataset_id = if (length(obs_id)) obs_id[1] else NULL)
  cat(glue("wrote {basename(a$zip)} ({round(file.size(a$zip) / 1e6, 1)} MB), ",
           "content_hash {substr(a$content_hash, 1, 12)}"), "\n")
  # the fingerprint rides in the manifest dwc_archive() wrote, so the next release can
  # tell whether this archive is still current without rebuilding it
  m <- jsonlite::fromJSON(a$manifest, simplifyVector = FALSE)
  unlink(a$manifest)   # the dataset's manifest lives beside its object folders, one per dataset
  # identities, the release tables' vocabulary: content_hash names the object (data + metadata +
  # format), data_hash the data alone; files_hash is dwc_archive()'s md5 over the CSVs
  m$files_hash        <- m$content_hash
  m$since             <- RELEASE
  m$checked_version   <- RELEASE
  m$content_hash      <- ch
  m$data_hash         <- fps[[k]]$data_hash
  m$path              <- obj_rel
  m$url               <- glue("{BASE_HTTPS}/{obj_rel}")
  m$sha256            <- digest::digest(a$zip, algo = "sha256", file = TRUE)
  m$bytes             <- file.size(a$zip)
  m$input_fingerprint <- list(hash = fps[[k]]$hash, parts = as.list(fps[[k]]$parts))
  writeLines(jsonlite::toJSON(m, auto_unbox = TRUE, pretty = TRUE, null = "null"), prev_man)
  results[[k]] <- tibble(dataset_key = k, status = "built", built_from = RELEASE,
                         n_event = nrow(ev), n_occurrence = nrow(oc), n_emof = nrow(mf),
                         content_hash = ch, archive = basename(a$zip))
}
```

## Upload — a deliberate manual step
