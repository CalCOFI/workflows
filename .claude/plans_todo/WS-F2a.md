## Do
1. **`scripts/fetch_species_media.py`** — Python ≥ 3.11, stdlib + Pillow only; flags `--release` (default: `_data/taxa.json`'s), `--only <file of taxon_keys>`, `--limit N`, `--resume` (default on: a taxon whose cache record is complete is skipped; `--refresh` redoes it), `--dry-run`, `--upload`. Per taxon in `taxa[]`:
   a. **silhouette** — PhyloPic by `ids.worms_id` (`/resolve/marinespecies.org/taxname/{id}?embed_primaryImage=true`), else by name at each rank from the taxon's own name up the lineage (genus, family, order, class, phylum, kingdom) via `/nodes?build=&filter_name=&embed_items=true&embed_primaryImage=true`; keep the image uuid, `specificNode` title → `taxon_shown`, `steps_up`, contributor, licence URL → the short name, the vector URL; download the SVG, strip the prolog/DOCTYPE/metadata, set `fill="currentColor"`, record `viewBox`, `aspect`, `svg_inner`; `length_axis` = "w" when aspect ≥ 1 else "h".
   b. **Wikidata** — one SPARQL per batch of 100 taxa: `VALUES ?worms {…}` on P850 (and a second query on P815 for ITIS-keyed taxa) → item, P18, the enwiki sitelink, P3151 (iNat), P3444 (eBird), P938 (FishBase), P846 (GBIF), P2043 (length, as a last-resort size). Batch: never one query per taxon.
   c. **text** — Wikipedia REST `page/summary/{title}` from the sitelink: `extract`, `revision`, `timestamp`, the article title; `about = "genus"` when the article title is one word and the taxon is a species (or the summary's `description` starts with "genus"); the lead = the first one or two sentences ≤ 320 characters (the probe's `sentences()` rule in `build.py`).
   d. **photo candidates** — in this order, each with `taxon_shown`: Commons P18 and the files of `Category:{scientific name}` (imageinfo `extmetadata` + dimensions; `taxon_shown` from the file's categories that match a name in `taxa.json`, else the page's taxon when the file title contains it, else skip); iNaturalist `/taxa/{id}` `taxon_photos` then `default_photo` (`taxon_shown` = the iNat taxon's name); GBIF `occurrence/search?taxonKey=&mediaType=StillImage&limit=50` (`taxon_shown` = the occurrence's `species`/`scientificName`). Normalise licences to `CC0 1.0 | Public domain | Public Domain Mark | CC BY x | CC BY-SA x | CC BY-NC x | CC BY-NC-SA x`; drop any ND, `null`, "all rights reserved", unknown. Rank per D7 (taxon first, curated over raw, licence order, then landscape ≥ 800 px). Pick `photo`; pick `drawing` from Commons candidates whose categories or `ImageDescription` mark an illustration, plate, drawing, painting or engraving (state the rule in a comment).
   e. **plate** — for species whose lineage includes Chordata and a fish class (Actinopteri, Actinopterygii, Teleostei, Elasmobranchii, Holocephali): GET `https://apps-afsc.fisheries.noaa.gov/ichthyo/images/ill/{Genus}!{species}Page.gif`; a 200 with an image body → `plate` with the credit line of D5 and the IIS page URL; ≤ 1 request per second, cache negatives too.
   f. **size** — WoRMS `AphiaAttributesByAphiaID/{id}`: a *Body size* with `Type = maximum`, `Dimension = length`, `Unit` cm or mm, `qualitystatus = checked` preferred → `size {m, length_type (from the WoRMS "Type"/FishBase LType if present), kind: "max", source: "worms_attribute", source_id}`. If `sizes.json` (WS-F2b) is present, fill `size` from FishBase/SeaLifeBase where WoRMS has none (precedence WoRMS › FishBase › SeaLifeBase › Wikidata P2043) and `early[]` + `refs{}` from it.
   g. **thumbnails** — Pillow: 800 px long side, WebP quality 80, for `photo`, `drawing`, `plate` (the plate keeps its aspect); write `{slug}/photo.webp`, `drawing.webp`, `plate.webp`, `silhouette.svg` under `.cache/species-media/{release}/`; `w`, `h`, `focal: [0.5, 0.5]`.
   h. **output** — `.cache/species-media/{release}/taxa_media.json` in Appendix A's shape with `coverage{}` and `policy{}`; `--upload` rsyncs the folder to `gs://calcofi-files-public/species-media/{release}/` and sets `cached` to the object path.
   Every request: a User-Agent `calcofi.io species-media/1.0 (https://calcofi.io; <contact>)`, timeouts, three retries with backoff, per-host rate limits (PhyloPic ≤ 2 rps, Wikidata ≤ 1 query/s, Commons ≤ 2 rps with 50 titles per call, Wikipedia ≤ 4 rps, iNaturalist ≤ 1 rps, GBIF ≤ 4 rps, WoRMS ≤ 3 rps, NOAA ≤ 1 rps). A source that fails for a taxon leaves that slot `null` and is logged; the run continues.
2. **`scripts/check_species_media.py`** — reads the JSON: every non-null asset has an allow-listed licence, a non-empty credit, a `page` or `url`; `taxon_shown` is the taxon or within two ranks of it (walk `taxa.json`'s `parent_taxon_key`); silhouettes on ≥ 95 % of taxa; a 5 % sample of `url`s answers 200; exit non-zero with a list otherwise.
3. **`scripts/fetch_release.sh`** — after the release files: fetch `species-media/{release}/taxa_media.json` from the bucket into `_data/taxa_media.json`, silently absent when the object does not exist (the generator then draws no faces). `.gitignore`: `_data/taxa_media.json`, `.cache/`.
4. **`.github/workflows/species-media.yml`** — weekly (Sunday 09:00 UTC) + `workflow_dispatch`: run the fetcher with `--upload`, using the same service-account secret the other workflows use; if the repo has none, write the workflow with the secret named and leave it `if: false` and say so.
5. **README** § The species catalog → *Faces · the fetcher*: the sources in order, the policy (D7) in five lines, the cache, the check, how to rerun for one taxon.
6. **Run** `--only cast.txt` and diff against `taxa_media.sample.json`: silhouette uuids and licences must match; a photo may differ only when the ranking places a better-licensed or better-matched file first (say which). Then `--limit 200` (the first 200 taxa) for timing; project the full runtime.

## Gates (stop and report)
- A source refuses the whole cast (HTTP 403/429 that retries do not clear); the bucket cannot be written; the projected full runtime > 4 h.
- `check_species_media.py` fails on the cast output.
- You are tempted to type a licence or a credit a source did not return: leave the slot `null` instead.
